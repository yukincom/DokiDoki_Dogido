# ドギド・語句抽出の教材

実際の発話を少しずつため、CSVを保存して「教材ZIPを作る」を押すと、Google Colab用のNotebookと教材.zipができます。分類器とは別の、日本語文字BERTによる変更元・変更先の抽出用です。

## 毎回の流れ

1. 「ModernBERT 学習教材」アプリのプロジェクトで **ドギド・語句抽出** を選びます。
2. **教材CSVを開く** から教材.csvを開き、実例を追記します。ExcelやTablecruncherで編集し、**CSV UTF-8** で保存します。
3. **教材ZIPを作る** を押します。CSVを画面へドロップする方法も使えます。
4. 出力フォルダの **語句抽出_T4学習.ipynb** を [Google Colab](https://colab.research.google.com/) で開きます。
5. ランタイムをT4 GPUにして上からセルを実行し、同じフォルダの **教材.zip** を選びます。
6. **学習する → 評価・テストする → 結果ZIPを保存** を押します。

初期教材は承認済み実例22件＋合成246件です。学習186件、調整41件、テスト41件で、既知の実ログ5件は「回帰」に分けています。合成を自動で増やす処理はありません。原文の誤字、改行、句の語尾はそのまま記入します。アプリはモデルの学習・外部送信を行わず、ローカルで教材をまとめます。

## CSVに記入する内容

| 列 | 記入方法 |
|---|---|
| 使う | はい／保留／いいえ。まだ正解を決めていない発話は保留で残せます |
| ID | 行の名前。既存IDは維持。新しい独立例は空欄でも自動採番します |
| 用途 | 学習／調整／テスト／回帰。空欄は学習 |
| グループ | 必須。同じ句、その改訂、同じ変更内容の言い換え・表記違いは同じ名前にします |
| 句ID | ログに句のIDがあれば記入。同じ句の版違いには同じIDを使います |
| 現在の句 | 発話時点の句を3行のまま記入。不明なら空欄にして、推測で補いません |
| 発話 | 認識された本人の原文。句の語句も依頼の言い回しも補正しません |
| 変更元 | 原文に明示された変更前の語句。発話にない場合は空欄 |
| 元の出現番号 | 同じ語句が原文に何回もある場合だけ、先頭から1、2…で指定 |
| 変更先 | 原文に明示された変更後の語句。発話にない場合は空欄 |
| 先の出現番号 | 同上。変更元・変更先それぞれの語句を原文中で数えます |
| 抽出なし | 抽出する具体語がない正解例だけ「はい」。未注釈を空の正解として学習させません |
| 種別 | 実例／合成・正表記／合成・認識表記。空欄は実例 |
| メモ | 自由記入。モデルへは送りません |

変更元・先の文字位置はアプリが求めます。例えば「朝の村から夕方の村に変えて」なら変更元「朝の村」、変更先「夕方の村」です。依頼に使われる「から」「に変えて」は入れません。一方、句としての「広場の中に」を残したい場合は、末尾の「に」も変更先に含めます。

同じ語が二度ある「花を花に変えて」は、変更元「花」・元の出現番号1、変更先「花」・先の出現番号2とします。語句が原文にない、出現番号が曖昧、同じ位置を変更元と先に指定している場合は生成を止めて行番号を表示します。漢字へ直した言葉を正解語に書くのではなく、発話原文にある表記を使います。

CSVのセル内の改行はそのまま使えます。表計算アプリからCSVで保存すると引用符が付きます。手入力でCSVを編集する場合、カンマ・改行・引用符の扱いに注意してください。

## 調整・テストへ同じ内容を混ぜない

学習は重みの更新、調整は最良モデルの選択、テストは選択が終わった後の確認です。回帰は前回の失敗など、すでに知っている例の再確認です。回帰は学習にも選択にも使いません。

同じグループ・句ID・現在句・発話・変更元・変更先が用途をまたぐ場合、ZIP生成を止めます。意味が似ていて表記が違うだけの例は自動では判定できません。そのような派生を追加するときは、元の例と同じグループ・用途にしてください。用途は毎回ランダムに振り直しません。

新しい独立した句をためながら、学習だけでなく調整・テストにも例を確保してください。「AからBに」、改行、語尾の助詞など、確認したい言い回しも調整・テストにそれぞれ独立した句で用意します。同じ原文の正解を見て教師へ移した場合、その例を新しい未使用テストとは扱いません。

## Colabの学習・評価

- 公開の `tohoku-nlp/bert-base-japanese-char-v3` の固定版から、毎回データ全体で学習します。以前の学習済みモデルへの継ぎ足しではありません。
- 上限20周、seed42。調整の全範囲完全一致数、同数なら範囲F1の順で比較します。改善が3周続けてなければ停止し、最良の重みを保存します。
- 「評価・テストする」は保存したモデルを読みます。再学習せず、テスト結果でモデルを選び直しません。
- 全範囲完全一致、範囲の適合率・再現率・F1、変更元／変更先別の成績、原文・正解・予測を保存します。学習内確認、調整、テスト、回帰は別の成績です。
- 「1件試す」には現在の句と発話を入力します。これは試し読みで、教材へ自動追加しません。
- 結果ZIPには最良モデル・文字辞書・入力形式・学習条件・各周の成績・全予測・失敗一覧・元CSVが入ります。本体への採用は別作業です。

Google Drive保存を選ぶと成果がDriveに残ります。学習が中断された場合は、途中の試行を保持し、次の「学習する」で基礎モデルから新しい試行を始めます。途中のoptimizer状態からの再開ではありません。完了済みの同じ教材では、学習ボタンを押し直しても完成モデルを保持します。

[Colab公式FAQ](https://research.google.com/colaboratory/faq.html)のとおり、無料GPUの割り当てや実行時間には制限があります。T4上での学習精度・音声認識・Minecraftでの編集動作は、ローカルの教材検査とは別に確認してください。
