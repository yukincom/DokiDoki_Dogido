# ModernBERT 学習教材

**「ドギド・語句抽出」プロジェクトは[専用の使い方](語句抽出の使い方.md)を参照してください。** 変更元・変更先の語句を記入するCSVと日本語文字BERTを使います。以下は分類ラベルを学習するプロジェクトの説明です。

Excelで編集したCSVをアプリへドロップし、Colabの無料T4向けNotebookと教材ZIPを作ります。学習方法は公開ベースのModernBERT-Ja 30Mからの再学習です。

## プロジェクト

初回にフォルダ選択画面が出たら、ドギドの「教材作成」フォルダを選び「このフォルダを使う」を押します。macOS上で分類一覧と教材を読むための選択です。別の場所のプロジェクトは「プロジェクトを開く…」からフォルダを選べます。選択した場所は記憶します。

アプリ上部でプロジェクトを選びます。ドギドは以前と同じ教材フォルダを使い、元の通常914件・川柳424件を引き継ぎます。ニャムルは独立した空のプロジェクトを用意しています。分類や実発話の内容は補作していません。

新しく作るときは「新規プロジェクト…」へ名前を入れます。`dev_tools/request_classifier/教材作成/プロジェクト/名前/` に次のファイルを作ります。「入力フォルダ」からFinderで開けます。

| ファイル | 内容 |
|---|---|
| 分類一覧.csv | このプロジェクトだけの分類定義 |
| 教材.csv | このプロジェクトだけの発話・正解・用途 |
| project.json | アプリが使うプロジェクト情報。通常は編集不要 |
| 出力/ | 生成したNotebook・ZIP・用途別の全教材CSV |

別のプロジェクトのCSVを一緒にドロップすると停止します。CSVと同じフォルダのproject.jsonからプロジェクトを自動選択します。別の場所へ保存したCSVを使う場合は、アプリで対象プロジェクトを選んでからドロップしてください。

## 1. Excelで分類一覧を編集

「分類一覧を開く」から開き、次の列を埋めて **CSV UTF-8（コンマ区切り）** で保存します。新規ファイルはExcelでそのまま開けるBOM付きUTF-8です。

| 列 | 入力 |
|---|---|
| モード | 新規プロジェクトは「分類」。1モードだけなら空欄可 |
| ID | 0、1、2…と重複なく連続した番号。行を並べ替えてもIDは保ちます |
| 正解分類 | Excelで使う分かりやすい名前 |
| 機械名 | モデルの出力ラベル。例：`category_a`。プロジェクト内で一意にします |
| 備考 | 自由記入。モデルの入力には含めません |

少なくとも2分類を定義します。機械名とIDは利用先の契約になるので、学習後に変更した場合は別のモデルとして扱ってください。ドギドの既存分類IDは元教材から保持し、変更・削除しません。既存の分類一覧CSVも引き続き使えます。

## 2. Excelで教材を編集

教材.csvに発話を追加し、同じく **CSV UTF-8** で保存します。以前のドギドの追加データ.csvも使えます。

| 列 | 入力 |
|---|---|
| 使う | 空欄・はいで使用、保留・いいえで保管だけ |
| モード | 分類一覧と同じ名前。1モードだけなら空欄可 |
| 発話 | 分類する文章の原文 |
| 正解分類 | 分類一覧の「正解分類」または「機械名」 |
| メモ | 任意。モデル入力に含めません |
| グループ | 同じ会話・言い換えは同じ名前と用途にまとめます。独立例なら空欄可 |
| 用途 | 学習・調整・テスト。空欄は学習 |

trainは学習用、devは最良epochの選択用、testは選択後の確認用です。新規プロジェクトでは3用途すべてに実際の教材を用意し、全分類に学習例を入れてください。発話の表記揺れ・ID・グループが用途をまたぐ場合は生成を止めます。意味が似た言い換えは自動判定できないため、同じグループにします。

教材.csvへ蓄積した全行を毎回使います。別のCSVも使う場合は必要なファイルをまとめてドロップします。過去にドロップした別ファイルを次回へ自動追加することはありません。

## 3. アプリへドロップ

保存した教材CSVをアプリの画面かアイコンへドロップします。選択中のプロジェクトの教材.csv（ドギド分類は追加データ.csv）なら「教材ZIPを作る」ボタンでも生成できます。分類一覧.csvを教材としてドロップする必要はありません。

CSVの隣の「出力」に、ModernBERT_T4学習.ipynb、教材.zip、最初に読む.md、生成結果.json、教材の中身/を作ります。生成結果にはプロジェクト名・分類ID・元教材と追加分の件数・用途間の混入検査を残します。以前の出力は保持します。

## 4. Colabで学習・テスト

1. [Google Colab](https://colab.research.google.com/)にNotebookをアップロードし、ランタイムをT4 GPUにします。
2. 上からセルを実行し、同じ出力フォルダの教材.zipをアップロードします。
3. Google Driveへの途中保存を選び、最後のセルに出る **「学習する」→「テストする」→「結果ZIPを保存」** を押します。

テストでは保存済みの最良モデルを読み、再学習しません。正解率・macro F1・分類別成績・誤分類を表示します。結果ZIPにはモデル、tokenizer、プロジェクト・入力形式・分類ID、予測、成績、元CSVを含みます。本体への採用は別の作業です。

ドギドは既存と同じ入力整形を保ち、新規プロジェクトは発話本文だけをモデルへ渡します。利用先でもモデルのconfig.jsonに保存した`classifier_input_format`と`label2id`を使ってください。

既存testは既知の診断集合です。test結果を見て教材や設定を調整すると、そのtestも既知の診断集合になります。無料T4の割り当て・実行時間や、作成したモデルの精度は保証されません。[Colab公式FAQ](https://research.google.com/colaboratory/faq.html)

途中再開には同じNotebookとZIPを使い、Drive保存をオンにします。ModernBERT学習フォルダ内の最後のepochから再開し、完了済みのモードは保持します。別プロジェクトや別設定の出力先へ混ぜて再開することはできません。
