# ドギド サーバー（Mac管理アプリ）

`apps/ドギド サーバー.app` を開き、本体とマイクをそれぞれ起動・停止します。起動済みなら起動元に関係なく状態を表示し、取得できる標準出力・標準エラーを「ターミナル出力」に表示します。「発言履歴を開く」で発言だけの画面を開けます。

アプリを開くだけでは本体を起動せず、閉じても稼働中の本体・マイクを停止しません。マイクは本体の稼働を確認してから起動できます。外部ターミナルへ直接出力していてログファイルがないプロセスの過去出力は、起動元で確認します。

## ビルド・検査

macOS 13以降とXcode Command Line Toolsを使います。本体の既存 `dogido-llm` 環境・設定・起動ファイルを利用します。リポジトリのルートから実行してください。

```sh
python3 apps/dogido-server-manager/Tools/build_app.py --output 'apps/ドギド サーバー.app'
python3 apps/dogido-server-manager/Tools/run_tests.py
```

ビルドは既存アプリを上書きしません。更新時は別の出力名を指定します。アプリにはビルド元フォルダを登録するため、本体を移動した場合は再ビルドします。検査は一時フォルダと空きポートの模擬プロセスだけを起動・停止します。

アプリから起動したログは `.dogido_tools/server-manager/logs/` に追記します。発言履歴は既存 `/dogido?view=utterances` を使い、本体再起動時に消える表示履歴です。仕様と検証範囲は[実装記録](../../docs/2026-10-11-server-manager-and-checks.md)を参照してください。
