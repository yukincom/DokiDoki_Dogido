# ドギド配置検討

## 考え顔の動き（2026-09-15・見た目のみ）

「考え顔を試す」で作者の `thinking2.png` に切替。通常は幅9%。「動きを大きく見る」は細部確認用の幅28%で、再押下で元の幅へ戻る。原画は無加工のPNGをコピーし、反転・描き直しはしない。全体は3.8秒周期の上下浮遊、輪郭は5.2秒周期の変位（原画座標で各軸最大32px）。初版の変位はほぼ知覚できないという作者の確認を受け、変位幅・変位場のコントラスト・時間変化を強めた。顔・眉・頬・口・両手・小さい思考の丸は、変位範囲より余裕のある固定領域に元画像を重ねて保護する。固定領域の境界は単色の体内を通し、内側の線が歪む／二重になるのを防ぐ。

「ゆっくり、ホヨホヨ」オフ、OSの動きを減らす設定では変形も浮遊も停止。非表示タブでは輪郭更新を止める。通常顔と考え顔の二重表示はせず、「掛け軸あり」「危険」へ切替で通常顔に戻す。このブラウザ画面は見た目確認用で、実サーバーとは接続しない。2026-09-16にFabric側へ別実装として原画の考え顔・外周変形と実生成区間の切替を追加。生成終了後は通常顔へ戻る。ゲーム用は連続メッシュで顔・手を固定し、ブラウザのSVGフィルタと変位波形は同一ではない。実ゲームの表示確認は未完了。

## 配置と掛け軸

リポジトリのルートをローカルHTTPサーバーで開き、`dev_tools/character-placement/` を表示する。

- ドギドの定位置は左下（幅9%・左2.5%・下4%）。盾との重なりは許容し、作者制作の太線原画 `Dogido_nomal.png` を無加工で使う。CSS・画像座標・描画面の左右反転は禁止。位置・掛け軸・文字は変えない。「ドギドの位置」で比較用の右上案にも戻せる。通常顔の瞬きはFabricとプレビューの両方で、開眼4.5秒・閉眼140ms。同じ大きさの作者原画 `Dogido_nomal_close.png`（ゲーム資産名 `character_closed.png`）を先読みして切り替える。動きオフ・動きを減らすOS設定・非表示タブでは開眼に戻して停止し、表示復帰時は開眼から再開。考え顔の閉眼原画はないため、考え顔には瞬きを適用しない。
- 「掛け軸あり」で大きな縦書き三列を右下／左下に約1秒で表示。「終了・じわっと」は約1秒で消え、「危険・パッと」は出現／終了のアニメーション途中でも即非表示にする。「もう一度、浮かび上がる」で再生でき、通常の切り替えは現在の透明度から続く。動きを減らすOS設定では即時表示。いずれも句の内容は消さない。
- 採用した掛け軸は右下・幅26.5%・高さ74%・右端1.5%・下10.5%、文字は画面幅の3.5%。これを初期値として、幅・下余白・文字サイズを調整できる。幅を広げると中央のHUDにも重なるため、地上と洞窟の両方で比較する。
- 表示例は仮文。画面内の三つの入力欄から差し替えられるが、保存・音数判定・音声修正・本体workshop・戦況とは接続していない。
- 「句を直す」で、左から上・中・下の独立した選択バーが即時表示される。各ボタンを押すと対応する本文の一列だけに濃色3px枠・淡い橙背景、選択ボタンに橙背景・太枠、「上／中／下の句 選択中」が同時に付く。本文は右から上・中・下のまま。色だけで選択を表さず、点滅や選択フェードは使わない。
- 選択後の入力欄から、その行だけを仮の表示へ反映できる（試験用1〜7文字・空欄不可・未保存）。「選択表示を閉じる」「終了」「危険」で選択を解除する。実装は `edit-preview.js`。音声入力を模擬するボタンであり、実際の音声認識・採用・保存処理ではない。
- 操作音は明示クリック時だけWeb Audioで約60msの短い音を鳴らす。「操作音」で無音にでき、再読み込みや自動表示では鳴らさない。音が使えなくても選択・編集表示は動く。スピーカーからの実聴取は未確認。
- ブラウザで三つの対象照合・対象行のみの更新・空入力拒否・通常モードでの解除を確認。旧画像での反転表示は撤回し、作者制作の右向き原画へ変更。選択枠／紙のコントラストは約9.90:1、選択ボタンの文字／橙背景は約6.17:1（CSS色値による計算）。色覚シミュレーションや全画面サイズの適合確認は未実施。
- 作者の `資料/掛け軸資料/画面収録 2026-09-12 14.02.59.mov` を元にしたローカルの `gameplay.mp4` を使用。
  録画の3〜60秒、ゲーム領域854×480、原画面位置x=56/y=66。ゲーム外の黒い余白とタイトルバーのみ除き、体力・満腹度・ホットバーを残す。音声なし・30fps H.264。
- 洞窟は同じフォルダの `画面収録 2026-09-12 14.17.05.mov` から `cave.mp4` を作成。2〜42秒、同じ854×480領域・x=56/y=66を使用。元動画は変更しない。
- `gameplay.mp4` と `cave.mp4` は録画由来のローカル資料としてGit対象外。別環境では「昼・静止画」「夜・静止画」の同梱スクリーンショットへ切替できる。
- 作者の格の指定を優先し、一文字を省く「草の草」を参考にCSSで簡素な表装を試作。写真の豪華さは模倣せず、生成画像も使わない。参考: [野村美術・大和表装](https://nomurakakejiku.jp/lesson_lineup/yamato-style-mounting)。
- Fabric側も同じ右向き原画を反転なしで使い、左下配置へ接続済み。新版原画の実ゲーム表示は未確認。
