# ドギドの学習教材を作る

TablecruncherでCSVへ発話を追加し、保存したCSVを **「ドギド 学習教材.app」** のアイコンへドラッグ＆ドロップすると、Google Colabの無料T4向けNotebookと教材ZIPを作成します。

## 1. CSVへ追加する

1. `/Applications/Tablecruncher.app` を開き、このフォルダの **追加データ.csv** を開きます。
2. 一番下へ行を追加します。普段入力するのは **モード・発話・正解分類** です。列が狭い場合は列見出しの境界をドラッグして広げます。
3. 保存します。文字コードは **UTF-8** を使ってください。

| 列 | 書く内容 |
|---|---|
| 使う | 空欄または「はい」で学習候補に含めます。「保留」「いいえ」でその行を保管だけにします。 |
| モード | 「通常」か「川柳」。同じ対象外でもモードを分けます。 |
| 発話 | 実際に認識された原文。誤変換・文中の空白もそのまま残せます。 |
| 正解分類 | 分類一覧.csvから名前をコピーします。`not_target`等の機械名も使えます。 |
| メモ | 自由記入。元の誤分類や、その場の状況など。空欄でも構いません。学習本文へは渡しません。 |
| グループ | 同じ会話・似た言い換えをまとめたいときだけ同じ名前を入れます。通常は空欄で構いません。 |

記入例：

| 使う | モード | 発話 | 正解分類 | メモ | グループ |
|---|---|---|---|---|---|
| はい | 通常 | ドギド、こっちへ来て | ドギドの呼び寄せ | 自分のそばに来てほしい | |
| はい | 川柳 | 上の句を相談したい | 上五の行指定 | 行の指定だけ | |

**追加データ.csvには、10月28日・30日に収集した11件を入れてあります。** 正解例も含みます。まだ下方向の実例がないため、上方向の1件は「保留」にしてあります。元の分類・表示確率・推論時間などはメモと同梱の出典記録に残しています。

空から始める場合は **空のテンプレート.csv** を複製して使ってください。見本の記入例は、実発話として教材へ自動追加されません。

## 2. アイコンへドロップする

1. CSVを保存してから、Finderでこのフォルダの **教材を作る.app** アイコンへドラッグ＆ドロップします。本体は書類側の `DokiDoki-Dogido/apps/ドギド 学習教材.app` にあります。
2. アプリの画面へCSVをドロップするか、「CSVを選ぶ…」から選ぶ方法も使えます。複数CSVを同時に選ぶと一組の教材へまとめます。
3. 完了すると出力フォルダがFinderで表示されます。CSVと同じ場所の **出力 → ドギド教材-日時-識別番号** に保存されます。

| 出力 | 用途 |
|---|---|
| ドギド_T4学習.ipynb | Colabで開くNotebook |
| 教材.zip | そのNotebookへアップロードする教材と学習コード |
| 最初に読む.md | 件数、保留・重複、評価例の不足の案内 |
| 生成結果.json | 追加・訂正の内訳、設定、元CSVの記録 |

通常と川柳を両方含むCSVなら、Notebook内で別々のモデルを順番に学習します。片方だけならそのモードだけを作ります。作成するたびに新しいフォルダを作るので、前の教材は残ります。NotebookとZIPは必ず同じフォルダの組を使ってください。

## 3. Colabで無料T4を使って学習する

1. [Google Colab](https://colab.research.google.com/) を開き、「ファイル → ノートブックをアップロード」から **ドギド_T4学習.ipynb** を選びます。
2. 「ランタイム → ランタイムのタイプを変更」で **T4 GPU** を選びます。
3. 上から順にセルを実行します。教材のアップロードでは、同時に作った **教材.zipを1つ** 選びます。
4. 「Google Driveに途中保存する」は初期状態でオンです。表示されるGoogleの画面で自分のDriveへの接続を許可すると、`マイドライブ/ドギド学習/` に途中の重みと学習記録を保存します。
5. 学習が完了したら、最後のセルで **dogido-training-results.zip** をダウンロードします。Google Driveへ保存した場合はDrive側にも残ります。

無料枠でもT4を利用できますが、割り当て・実行時間は保証されません。接続できない場合は時間を置きます。Colabの有料プランや計算ユニットを持つアカウントでは、そのアカウントの課金・ユニット規則に従うため、無料枠で使いたい場合は契約・残高を確認してください。このツールから購入や課金の操作はしません。[公式FAQ](https://research.google.com/colaboratory/faq.html)

Driveへの途中保存をオフにした場合、ランタイムが消えると途中結果も失われます。再開したい場合は同じNotebookと同じZIPを使い、Driveへの保存をオンにして再実行してください。保存された最後のepochのcheckpointから再開し、完了済みのモードは再学習しません。途中のepochの計算はやり直す場合があります。

## 何を学習するか

- 通常は既存16分類、川柳は既存8分類。公開ベース `sbintuitions/modernbert-ja-30m` の固定版から、それぞれ全体を学習し直します。
- 現在発話だけを既存の入力形式へ整えます。メモ・正解理由・過去の誤分類はモデル入力に混ぜません。
- 無料T4を想定し、1シード（42）・最大10 epoch・batch 16・最大128 token・FP32です。以前の28学習やモデル合成は実行しません。
- 元のtrainへCSVを追加します。元のdev/testは固定のまま、devのmacro F1、loss、早いepochの順に最良モデルを選び、確定後にtest・trainを診断します。既知の診断用データなので、未知の実機精度の保証とは区別してください。
- 結果ZIPには最良モデル、tokenizer、分類別成績、全予測、誤分類、使用設定、環境情報、元CSVが入ります。本体へのモデル採用はこのツールの外で確認して行います。

## 上下の分類を学習したい場合

「通常」で **上を向く・下を向く** の実例を両方追加すると、既存のIDを保って末尾に2分類を足した **18分類** の教材を作ります。最初の上方向の例も「使う」を「はい」にしてください。

片方が0件なら、そのまま学習せず、どの分類の例が不足しているか表示します。上下の既存dev/test例はないため、生成結果にも「評価例なし」と明記します。18分類モデルは現行本体の16分類と契約が異なり、そのまま差し替えるためのものではありません。

「音チェック」は現在は検討案です。今回の音の質問は、収集時の指定どおり通常の「対象外」として入っています。

## エラーが出たとき

| 表示・状況 | 対処 |
|---|---|
| CSVの列や分類が不明 | テンプレートの列名と分類一覧.csvを確認します。 |
| 同じ発話に違う分類がある | CSV内のどちらを正解にするか決めます。同じ分類の重複は1件にまとめます。 |
| 既存dev/testと同じ発話・グループ | 評価への混入を避けるため、その行を「保留」にします。元の評価データは変更しません。 |
| 元のtrainと同じ発話 | 同じ正解なら追加せず、異なる正解なら出力教材のtrainだけを訂正します。内訳は生成結果.jsonに残ります。 |
| token上限を超えた | Colabのエラーに出た発話を確認し、長い発話を保留するなど教材を見直します。自動では切り捨てません。 |
| ZIPが違うと表示される | Notebookと同じ生成フォルダの教材.zipを選びます。ZIPの中身を後から編集しないでください。 |

アプリはmacOS標準の `/usr/bin/python3` を利用します。Pythonが見つからない場合はXcode Command Line Toolsの導入を確認してください。作成時のMacでは利用可能です。
