# A〜F 統合版の実機テスト（2026-11-02）

普段のドギドのサーバー・音声入力を使っていたら終了し、Minecraftもゲームを終了してから始める。共有のGGUFサーバーとVOICEVOXは普段どおり使う。

1. 同じフォルダの `1-統合版で起動.command` を開く。ドギドの撮影用Modをテスト版に切り替えて、統合したサーバーを起動する。
2. 声で試す場合は `2-音声入力.command` も開く。MinecraftをいつものFabric構成で起動し、ワールドに入る。
3. 画像なしとの比較はMinecraftの接続を切り、テストサーバーを終了して `3-画像なしで起動.command` で起動し直す。接続時の設定だけが変わる。
4. 通常版に戻るときはMinecraftとテストサーバー・音声を終了し、`4-通常版のModに戻す.command` を開く。その後は普段のドギドの起動方法を使う。

書類側の設定を読むので、モデル・ポート・音声・記憶保存先は普段と同じ。テストで採用・保存した句も普段の句集に入る。Modの切替対象は `dogido-fabric-client-0.1.0.jar` のみ。身体Mod・ワールド・Minecraftの起動構成には触れない。

| 試す場面 | 確かめること |
|---|---|
| A：竹林でパンダを見て話し、視野から外して発句。骨・腐った肉はホットバーの外に置く | 前置きと三行に渡った材料に現在の景色と過去のパンダの区別があり、枠外の持ち物が混じらない。実際に何を詠んだかは保存句で別に見る。 |
| B・F：「パンダさんもいるかな？」→視野を外し「あれ、さっきいたよね」→「他にはいる？」 | 現在の視認、少し前の視認、音だけを混同しない。対象を省いた質問では他の現在候補を残す。「村人はいま仕事の時間？」では日課と実際に見た行動を区別する。 |
| C：上五「暗闇の絵を暗闇のに」、単一案の直後「それにして」、複数案から曖昧に指定 | 最初の2件は対象行だけ変更しrevisionを一件保存。特定できない場合は聞き返して版を変えない。 |
| D・E：ドギドだけ旋回／パンダだけ移動／両方が動く | 変化時は照合できた4枚前と今回の2枚がこの順で届く。未比較・参照欠落は今回だけ。身体の方角と各画像のPLAYER枠が、実際の場面と合うか確認する。 |

返答の品質や速さの判定には、同じ場面での発話・送信画像数・入力トークン数（再利用分と新規分）・発声開始までの時間を記録する。合格条件の詳細：[A・B・C](../../docs/2026-11-02-senryu-materials-mob-chat-edit-input.md)、[D・E・F](../../docs/2026-11-02-vision-frames.md)。この版は実機確認用で、mainには採用していない。
