# A〜F 統合版の実機テスト（2026-11-02）

11月3日の[観測と共同注目の確認](../../docs/2026-11-03-body-observation-dialogue.md)と[川柳WS中の軽量観測・注視](../../docs/2026-11-03-workshop-observations.md)もこの統合版で試せる。

2026-11-03にA〜Fと追加修正を本線へ統合した。普段は書類側の `apps/ドギド サーバー.app` でサーバー・音声入力を起動し、対応ModでMinecraftを起動する。[通常の起動・設定](../../README.md#1-本体の準備と起動)と[Modの導入](../../adapter/minecraft-fabric/README.md)を参照。

このフォルダの番号付きコマンドは、統合前のテスト版専用。とくに `4-通常版のModに戻す.command` は当時のModを復元するため、現在の本線への切り替えには使わない。

| 試す場面 | 確かめること |
|---|---|
| A：竹林でパンダを見て話し、視野から外して発句。骨・腐った肉はホットバーの外に置く | 前置きと三行に渡った材料に現在の景色と過去のパンダの区別があり、枠外の持ち物が混じらない。実際に何を詠んだかは保存句で別に見る。 |
| B・F：「パンダさんもいるかな？」→視野を外し「あれ、さっきいたよね」→「他にはいる？」 | 現在の視認、少し前の視認、音だけを混同しない。対象を省いた質問では他の現在候補を残す。「村人はいま仕事の時間？」では日課と実際に見た行動を区別する。 |
| C：上五「暗闇の絵を暗闇のに」、単一案の直後「それにして」、複数案から曖昧に指定 | 最初の2件は対象行だけ変更しrevisionを一件保存。特定できない場合は聞き返して版を変えない。 |
| D・E：ドギドだけ旋回／パンダだけ移動／両方が動く | 変化時は照合できた4枚前と今回の2枚がこの順で届く。未比較・参照欠落は今回だけ。身体の方角と各画像のPLAYER枠が、実際の場面と合うか確認する。 |

返答の品質や速さの判定には、同じ場面での発話・送信画像数・入力トークン数（再利用分と新規分）・発声開始までの時間を記録する。合格条件の詳細：[A・B・C](../../docs/2026-11-02-senryu-materials-mob-chat-edit-input.md)、[D・E・F](../../docs/2026-11-02-vision-frames.md)。実機での確認項目は本線でも引き続き使う。
