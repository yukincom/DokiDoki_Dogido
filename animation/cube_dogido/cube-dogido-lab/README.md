# Cube Dogido Lab

Minecraft Java 1.21.11 / Fabricで動く3Dドギドの身体です。浮遊する既存モデルに、移動・HP・休息・食事・復活を持たせます。

0.7.12ではBERTの明示呼び寄せ・注視をAPI v11へ接続します。相対8方向は身体を基準にし、呼び寄せは所有個体と安全な配置を既存処理で確認します。近くへの帰還後に「そばに留まる／その場でプレイヤーを見る／顔が見える位置へ近づく」を一度だけ選び直します。周囲と会話を見て、発話と次の行動を一回で選びます。離れると安心度が下がり、そばや顔の見える位置で回復します。安全な待機時は安心度に応じて周辺への注意が広がります。[仕様・確認状況](../../../docs/2026-10-20-reassurance.md)を参照してください。

発話中は、話題にした現在のモブや実音の地点へ向きます。明示注視を優先し、待機中は向きを保ちます。コードによる定期的な見回しは行いません。[発話と視線の仕様](../../../docs/2026-10-18-body-speech-gaze.md)。

## 導入

0.7.12は向きの競合を修正し、注視完了後から5秒保持します。検証・配備の状態は[今回の記録](../../../docs/2026-10-25-body-orientation-scene.md)を参照してください。

1. Minecraftを終了する。
2. 使用する起動構成の`mods`で旧`cube-dogido-lab`を退避し、`build/libs/cube-dogido-lab-0.7.12.jar`へ置き換える。同じModの新旧を同時に入れない。
3. 会話へ接続する場合は、対応するadapter（build `0.1.0+20261025orientation`）とRustのHTTP観測v3・自律制御v2も揃える。
4. Minecraft **1.21.11**、Fabric Loader **0.18.4以上**、Fabric APIで起動する。

2D表示用Modと併用できます。2D表示は既存Modの`/dogidohud hide`・`/dogidohud show`で切り替えます。身体単体の試験にHTTPサーバーやLAN公開は不要です。

## 最初の操作

呼び寄せは次の一つで試せます。所有する身体があれば寄ってきて、未登録なら近くの未所有個体を結び付け、いなければパーティクルとともに一体だけ出現します。FOLLOWは自動で開始します。

```mcfunction
/dogidobody call
```

登録済みの身体が未ロードなら増やさず、読み込みを待ちます。近くに未所有の身体が複数ある場合は、従来の`/dogidobody bind @e[type=dogido_experiment:dogido,sort=nearest,limit=1]`で対象を明示します。音声・文字での明示的な呼び寄せは、共通BERTの`dogido_recall`分類から同じ呼び寄せ処理へ接続します。

## 身体のルール

- HP上限は20。持ち主がサバイバル／アドベンチャーのときだけ通常ダメージを受けます。クリエイティブ／スペクテイター、持ち主不在中は通常ダメージを受けません。
- ブロックを通過でき、落下・溺れは無効。葉以外の衝突形状に身体が重なり続けると壁内滞在に数えます。
- 壁内の猶予は初期値100tick。その後1HPずつ20tick間隔で損耗します。持ち主が同じ次元にいるDIRECTの待機・休息中（再ロード後の未指示待機を含む）は、身体から3ブロック以内のロード済み・境界内・生体やブロックと重ならない場所へ自動復帰します。候補がなければ約1秒後に再確認し、移動指示・呼び寄せ・HP0中・操作の明示無効化や期限切れ中には介入しません。ダメージ無効のモードでは壁内損耗も無効です。
- `REST`を指定して静止すると、初期値100tick待った後、60tick間隔で1HP回復します。被弾・移動で休息の蓄積は途切れます。HP低下だけでは休みません。
- 食事は一個を実際に消費し、栄養値に相当するHPを上限まで回復します。通常の消費効果と容器の残りも処理します。空腹ゲージや食事アニメーションはありません。
- 持ち主が食べ物を持って身体を右クリックすると、その一個を与えられます。HP満タン・倒れている間は受け取りません。
- フィールドの食料は、落ちている可食アイテム、実のあるスイートベリー／グロウベリー、成熟したニンジン／ジャガイモ／ビートルートを扱います。植物は食べた後、実なし／成長初期へ戻ります。
- HP0で倒れ、初期値100tick後に**持ち主の現在座標**で全回復して復活します。個体の所有関係を保持し、経験値・通常ドロップを発生させません。新しい世代でFOLLOWを再開します。
- 持ち主不在・復活位置未ロードの場合は理由を返して復活を待ちます。身体が未ロードの場合、読み込み直後まで時間は進まず、別個体を自動作成しません。

20tickは通常動作時の約1秒です。ポーズやサーバーの処理速度により実時間は変わります。時間・回復量は実機調整用の初期値です。

DIRECTの指示移動では火・溶岩や敵からの距離を理由に移動先を差し替えず、同一次元で遠く離れただけでは自動ワープしません。生きたプレイヤーやモブとの物理衝突、読み込み範囲とワールド境界は移動側で検査します。

## 身体単体の試験コマンド

| コマンド | 内容 |
|---|---|
| `/dogidobody direct` | DIRECTの待機へ切り替える |
| `/dogidobody move ~ ~1 ~4` | 指定座標へ移動する。`~`はコマンド実行者が基準。身体から32ブロック以内 |
| `/dogidobody rest` | 現在地で休息する |
| `/dogidobody wait` | 現在地で待つ。休息回復は行わない |
| `/dogidobody food` | 身体から8ブロック以内の、見通せる食料候補IDを表示する |
| `/dogidobody eat <food_id>` | 表示された一件を指定して食べる。現在2ブロック以内で届くことが必要 |
| `/dogidobody call` | 身体を解決して呼び寄せる。水平2ブロック以内、通常は正面・採掘中は横か後ろ。到着後は通常の動きへ戻る |
| `/dogidobody status` | 動作・HP・壁内時間・復活待ち・位置を表示する |
| `/dogidobody unbind` | 持ち主との結び付けを解除する |

`food`の候補は100tick以内に再照合します。遠い食べ物には、まず移動が必要です。

登録・呼び寄せ・既定の再読み込みでFOLLOWが始まります。`/dogidobody follow`でも距離追従と危険回避を開始し、「身体操作: follow」と表示します。通常の接近はモデルが選び、既定では持ち主から12ブロック、または目線付近から上下4ブロックを超えるとコードが緊急追従を開始します。水平2ブロック以内の安全な位置まで寄り、狭い場所では上下にも着地点を探します。24ブロックを超えると安全な着地点へのワープを試み、その後も隣まで接近します。対応する会話サーバーとの接続中は、安全な待機時に、そばへ戻る・顔を見る・現在見える対象を見に行く・その場に留まるから、今可能な行動を選びます。`direct`でこの自律動作を終了し、行動指定待ちへ戻ります。

`explore`・`retreat`・`safe`・`hold`は従来のローカル試験コマンドです。外部の状態変更はDIRECTに限定し、外部からFOLLOWを有効化しません。有効なFOLLOWに対して、検証済みの`MOVE_TO`を観察移動・持ち主への接近として受け付けます。

### 最初の移動確認

```mcfunction
/dogidobody follow
/dogidobody status
```

持ち主が離れたときの追従を先に確かめます。安全な待機中は、環境反応に加えて安心度や見物候補による判断機会を設けます。モデルによる観察移動は毎回発生するものではありません。既見の種類も候補に含め、到着済みの同じ対象は2分空けます。止めるときは`/dogidobody direct`です。

### 調整

```mcfunction
/dogidobody tune speed 0.14
/dogidobody tune wall_grace_ticks 100
/dogidobody tune wall_damage_interval 20
/dogidobody tune wall_damage 1
/dogidobody tune rest_delay_ticks 100
/dogidobody tune rest_heal_interval 60
/dogidobody tune rest_healing 1
/dogidobody tune respawn_delay_ticks 100
```

安心度は保存せず、身体の再読込みや世代変更で50へ戻ります。調整値は個体の読み込み中だけ有効です。再読み込みや別次元への再生成では初期値へ戻ります。所有者・HP・倒れている状態・復活までの残り時間・復活回数・壁内時間は保存されます。ローカルのFOLLOW／HOLD／DIRECT／EXPLOREは保存し、古い保存データの既定はFOLLOWです。休息・移動・呼び寄せの一回指示と外部の期限付き要求は再読み込み後に指定し直します。

## ビルドと接続

Java 21以上でビルドします。

```sh
./gradlew --offline test build
```

既存キャッシュがない環境では、通常の`./gradlew test build`で依存関係を取得します。

- `build/libs/cube-dogido-lab-0.7.12.jar`：Minecraftへ入れるMod
- `build/libs/cube-dogido-lab-0.7.12-body-api.jar`：adapterのコンパイル用。`mods`へ入れない
- `build/libs/cube-dogido-lab-0.7.12-sources.jar`：ソース
