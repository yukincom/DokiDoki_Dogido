# LANサーバーPCのドギド専用接続

**旧セット用（2026-11-03に接続計画終了）。** 以下は、このセットをすでに持っている方のための操作記録です。新規のLAN共有には、専用SSHと鍵入り更新ZIPを使う方式を採用しません。

**2026-10-03: Rust本体セット向け。旧Pythonセットへの接続更新は終了しました。**

LANサーバーPCの固定共有モデルを、クライアントPCのドギドから使うための道具です。
LANサーバーPCのログインパスワードはクライアントPCで入力しません。
ファイル共有・リモートログイン・OSアカウント・管理者権限の設定変更はありません。

## 最初の導入

1. LANサーバーPCで、`default_model` の共有生成モデルが動いている状態にします。
2. このフォルダの **親Macで起動.command** をダブルクリックします。
   「ドギド専用接続を開始しました」が出たら、その画面を開いたままにします。
3. 同じフォルダにできる **息子Macへ渡す.zip** だけをAirDropで息子Macへ渡します。
4. 息子MacでZIPを展開し、**息子Macで接続を設定.command** を開きます。
   フォルダ選択画面では、Rust本体を含むドギドの **00_setup.command があるフォルダ** を選びます。
5. 息子Macで、更新したドギドの **ドギドを起動.command** を一つ開きます。
   専用接続・VOICEVOX確認・本体の準備完了待ち・音声入力を順に処理します。
   音声入力の「待機中」が出たら遊べます。パスワードは聞かれません。
   以前の01/02/03が動いている場合は、最初の切替時だけ03→02→01の順にCtrl+Cで終了してください。
6. Minecraftのドギド用起動構成で、シングルプレイを開始します。

接続更新は、既存の起動スクリプト・確認ツール・案内文と専用鍵だけを更新します。
以前の起動ファイルは `.dogido_tools/setup-backups/qwen-link-v1` に控えを残します。
接続更新はPython環境・.env・記憶・ワールドに触れません。初期設定をやり直す必要はありません。
旧Pythonセットや本体部品が不足したセットは、鍵やファイルの変更前に停止します。
この接続更新ZIPにはRust本体を含みません。移行にはRust本体を含む導入セットを用意し、
そのセットの「はじめに.md」にある記憶・ワールドの引継ぎ案内を確認してください。
起動時に本体ソースを書き換える旧処理は終了しました。

## 毎回の使い方・終了

次回からは、親Macで「親Macで起動.command」、息子Macで「ドギドを起動.command」を一つずつ開きます。
LANサーバーPC側のターミナルにも、クライアントPCの本体・音声・Dogido関連Minecraftログと共有モデルの応答時間が流れます。
各ターミナルを開いたまま使います。LANサーバーPCのスリープ中は接続できません。

終了は息子Macの起動画面で **Ctrl+Cを一回**、最後に親Macでも **Ctrl+C**。
LANサーバーPCの終了時には専用の接続とログ受信を停止します。共有モデル本体は止めません。
常駐登録はしないので、再起動後はこの道具を改めて開きます。

## ログ

親Macのターミナルに、次の内容を表示・保存します。

- `[SSH]` 接続・切断・接続拒否
- `[モデル]` 生成開始・完了・失敗、処理時間、生成トークン数
- `[クライアント/server]` ドギド本体のログ（会話や句、判断・エラーなど）
- `[クライアント/voice]` 音声入力・音声認識のログ
- `[クライアント/minecraft]` 実Fabric形式のDogido専用行・旧logger表記と直後のstack

保存先は起動時に画面に表示されます。
`~/Library/Application Support/Dogido-LAN-Server/logs/` に起動ごとのJSONLを保存します。
ログはプレイヤーの発話・句などを含みます。録音データ自体は転送しません。
クライアントPCにも `logs/family-client/` にログを残します。転送が一時的にできなくても、
ドギドを待たせずクライアントPCへの保存を続けます。両PCとも直近24時間だけ保持します。
長い通信断や終了直前の未送信分はLANサーバーPC側に届かない場合があります。Minecraftの全ログは転送しません。

## 接続の範囲

専用鍵で使えるのは、起動中の固定共有モデルへの現行Dogido要求とLANサーバーPC側への限定ログ送信だけです。
文単位stream、最大2枚の192px PNG、既知の川柳相談toolだけを通し、任意model・URL・file参照・toolは拒否します。
シェル・ファイル取得/書き換え・SFTP・他ポート転送・モデル変更は拒否します。
親Macの通常のSSH鍵登録先や、仕事用Macとのファイル共有は変更しません。
専用鍵を持つ相手は起動中の共有モデルを利用できるため、接続更新ZIPは公開しないでください。

親Macの接続先IPが変わったときは、親側を起動し直して新しい「息子Macへ渡す.zip」を再適用します。
`Address already in use` は同じ道具を二重に開いていないか確認します。
`Connection refused` は親側の起動画面と同じ家庭内LANへの接続を確認します。
ホスト鍵の不一致は無視せず、親側が作った新しいZIPを適用してください。
専用鍵の置き場は、新規導入では `~/Library/Application Support/Dogido-LAN-Server/` です。
以前の `Dogido-Qwen-Link/` がある場合は、既存鍵と接続更新を壊さないため同じ場所を継続利用します。
