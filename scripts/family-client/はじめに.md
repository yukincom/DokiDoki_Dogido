# 息子さん専用ドギド

**2026-10-03: 本体と音声入力はRustへ統一しました。旧Python本体の起動・起動時の書換えは終了です。**

自分のシングルプレイのワールドで遊ぶセットです。
親Macから借りるのはQwenの文章生成です。ドギド本体・記憶・マイク・音声認識・
VOICEVOX・音声再生は息子Macで動きます。MinecraftのLAN公開は不要です。
デバッグ用の本体・音声ログは親Macにも転送します。

## 接続更新だけの場合

Rust本体を含む現行セットで00の初期設定を済ませている場合、やり直しは不要です。
親Macから届いた **息子Macへ渡す.zip** を展開し、**息子Macで接続を設定.command** を開きます。
選択画面で、この **00_setup.command があるフォルダ** を指定します。
更新後は下の「毎回の起動」へ進みます。親Macのパスワードは使いません。
旧Pythonセットや本体部品が不足したセットへの適用は、ファイル・鍵の変更前に停止します。
小さな接続更新ZIPにはRust本体を含みません。旧セットからの移行には新しい導入セットが必要です。

## 初めて導入する場合

1. このフォルダを「書類」など使い続ける場所へ置きます。
   初期設定後はフォルダを移動しないでください。Apple Silicon / macOS 14.2以降用です。
2. MinecraftとMinecraft Launcherをそれぞれ **⌘Qで終了**し、`00_setup.command` を開きます。
   **その画面でEnterを押すと初期設定が始まります。** 既存の専用Python環境は再利用し、
   初回はPython 3.11から専用環境を作ります。既存の開発環境を更新せず、Qwenも導入しません。
3. 同じフォルダの **Minecraft設定.txt** を開きます。メモは最初から同梱され、
   00実行時に実際のフォルダの場所が記入されます。途中で失敗してもメモは残ります。
4. Minecraft Launcher → Java Edition → 起動構成 → 新規作成。
   バージョンは `release fabric-loader-0.18.4-1.21.11`、
   ゲームディレクトリはメモに書かれた **minecraftフォルダ** を指定します。
   テキストファイル自体のパスではありません。同版のFabricが既にあれば再利用できます。
5. 親Macで **親Macで起動.command** を開いてもらい、生成された **息子Macへ渡す.zip** を受け取ります。
   展開後、**息子Macで接続を設定.command** を開き、このドギドのフォルダを選びます。

同じ版・同じ起動内容のFabricは保持します。親子は別のMinecraftアカウントを使います。
既存ワールドを使う場合はコピーで試してください。新しい版のワールドを古い版で直接開かないでください。

## 毎回の起動

1. 親Macで共有Qwenと **親Macで起動.command** を開きます。
2. 息子Macで **ドギドを起動.command** を一つ開きます。
   親への専用接続、VOICEVOXの確認（未起動ならアプリを開く）、ドギド本体、音声入力の順に進みます。
   Rust本体の準備完了を確認するまでは、音声入力を開始しません。準備中の状況は同じ画面に出ます。
3. 音声入力の「待機中」が出たら、Minecraftのドギド用起動構成で遊びます。

初めて一括起動へ切り替える時だけ、以前の03→02→01を各画面でCtrl+Cして閉じてください。
既存の接続・本体が動いている場合は、二重起動せず案内を出します。
01・02・03は個別確認用として残していますが、毎回クリックする必要はありません。

息子側の終了は、この一つの画面で **Ctrl+C**。音声入力→本体→専用接続を終了します。
最後に親Macの専用接続もCtrl+Cで終了します。VOICEVOXと共有Qwen自体は自動終了しません。

起動時に本体ソースを書き換えません。旧config.py/audio.pyへの追加処理は終了しました。
同梱の警告音と、実際に必要になった台詞の音声を使います。

## 以前の記憶・ワールドを引き継ぐ場合

以前のフォルダはそのまま保持してください。このセットは記憶やワールドを移動・削除・コピーしません。
記憶は `.env` の `DOGIDO_MEMORY_DIR` で指定したフォルダを使います。
既存Rust版の記憶が `.dogido_memory/rust-migration` にある場合は、その保存先を指定したまま使えます。
旧Python版の記憶とRust版の記憶は別の保存先なので、自動で統合しません。
Minecraftの既存ワールドも、以前のゲームディレクトリを保持します。
新しい保存先を設定する前に、引き継ぐ記憶とゲームディレクトリを確認してください。

## 状況表示とログ

02と03の出力は、息子Macの画面に加えて親Macの専用接続画面にも流れます。
親Macには接続状況・Qwen処理時間・本体/音声ログを保存します。
息子Macには `logs/family-client/` に同じ本体/音声ログが残ります。
ログ転送は会話処理と別に動き、通信断の間もドギドと息子Macへの保存を継続します。
長い通信断や終了直前には、未送信ログが親Mac側に残らない場合があります。

- 02のQwen接続エラー：01の認証と親Macの専用接続・共有Qwenを確認します。
- 02のVOICEVOX接続エラー：息子MacのVOICEVOXエンジンの起動を待ちます。
- 01の `Address already in use`：01の二重起動を確認します。他のアプリは自動停止しません。
- 親のIP変更・ホスト鍵エラー：親Macが作った最新の接続更新ZIPを再適用します。
- `Minecraft設定.txt` が必要な場合、00と同じフォルダにあります。
- 音声前にMinecraftチャットで「ドギド、大丈夫？」と入力して、本体と2D UIを確認できます。
  発言履歴は既定で `http://127.0.0.1:5055/dogido` を開いて確認できます。
  `DOGIDO_BIND_PORT` を変更した場合は、その番号をFabricの接続先にも指定してください。

新規セットの記憶の既定は `.dogido_memory`、ワールドの既定は `minecraft/saves` です。接続更新時にも保持します。
親子の会話が重なるとQwenで待ちが発生する場合があります。実際の速度・8GBでの余裕は実機で確認します。
Chromeを使うWeb調査はこのセットでは未導入です。
