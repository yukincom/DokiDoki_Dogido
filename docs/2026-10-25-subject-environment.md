# 主体別の環境観測

2026-10-25。プレイヤーとドギドの降水・接触・遮蔽を、既存の共通観測で結びつける。

## 実装

既存の Fabricイベント → 身体感覚 → Rust共通観測 → 会話／環境対話を使う。HTTP窓口、モデル、生成回数、プロンプト指示は追加しない。コードが作る関係の文は観測材料で、返答本文・発話要否は既存のモデルに任せる。

- 共通観測は `subject_states.player` と `subject_states.dogido` を同じ外形で持つ。対象名、採取根拠、観測日時、各自のバイオーム・降水・頭上の遮蔽・空の見え方、接触の実測、整理済みの関係を渡す。旧 `player_environment` はこの中へ移し、接地・炎上も保持する。
- プレイヤーは元イベントの本人状態・世界・高さを使う。ドギドは既存の同じ身体sampleの姿勢・眼・実寸とclient世界を使う。自分の測定を相手へ補完しない。身体の接地・炎上は未測定なのでnull。
- 降水の雨／雪判定は既存の気候・高度の処理を共用する。本人に当たる雨はMinecraftと同じ足元と身体上端の `world.hasRain` から採る。木の葉や空の遮蔽だけでは、雨が当たらないと決めない。
- 接水と眼の水没を分離する。身体の接水は実寸を同じserver姿勢へ置いた箱と水面で測る。場所表現も接水だけで「水中」に強めず、泳いでいる・溺れている等の行動や危険を確定しない。
- 元の実測と関係を両方保持する。未取得は不明であり、falseや降雨終了ではない。接触フラグは濡れの残留・乾燥を表さない。

## 関係の例

| 観測 | 整理済みの材料 |
|---|---|
| 雨・本人への雨接触あり | 雨が降り、本人にも当たっている |
| 雨・雨接触なし・本人の頭上が葉・空が遮られている | 本人は木の葉の下で雨に当たっていない |
| 雨・雨接触なし・遮蔽未取得 | 雨は降っているが本人に当たっていない。理由は未確認 |
| 葉の下・雨接触あり | 葉が頭上にあっても本人に雨が当たっている |
| 接水あり・眼の水没なし | 水に触れているが眼は水面下ではない |
| 水または雨の接触あり・接水あり・雨接触未取得 | 雨への接触は未確認 |
| 雪・雨接触なし | 降雪中。本人に雪が当たるかは未観測 |

「雨宿りをしている」という意図や「雨が止んだ」という時間変化は、この一時点の関係から作らない。

## 鮮度と周期通知

身体の既存3秒期限・owner・世代・tick・revision検証を使い、別の保持タイマーは作らない。接触も同じsampleの期限で失効する。共通観測の現在値と差分を保持し、考慮済みにしても現在値は残す。日時だけの更新は変化に数えない。接地・炎上は従来の材料として保持し、今回の周期通知の条件へは加えない。

周期通知は比較した差分とrevisionを保ち、生成直前に現在の観測本文を更新する。旧遮蔽と新しい接触を混在させず、未提示の新しい差分も消費しない。失効・ポーズでは現在の関係を撤去する。比較時点の差分は `observed_at` 付きの記録として区別する。生成開始後の追いかけ再生成はしない。

## 他の整理候補（今回未実装）

- 木陰・洞窟等の場所と局所明るさ。「近くに照明はあるが、この位置は暗い」まで。暗いだけで夜・地下・危険とは決めない。
- 既存の位置関係と視認理由。「近いが遮られて見えない」「右後ろで視野外」。位置と視認は別の根拠を保つ。
- 視認と聴取の対応。同じ個体IDがあるときだけ「今は音だけ」へ結ぶ。種類一致だけで同じ個体にせず、IDを持たない匂いとは結合しない。
- 活動と場所の主体。「プレイヤーは採掘中」と「ドギドは木陰」を分ける。採掘の判定自体は既存処理を使い、道具所持だけでは作業中としない。

乗り物の種類と実移動、気候と高度による雨雪、モブの接水と接地は既存処理に整理済みなので、別の経路は作らない。
