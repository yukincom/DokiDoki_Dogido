# 2026-10-30 再生中の入力受付

本人の依頼により、読み上げ終了まで認識済み入力をFIFOへ保留する処理を外した。新入力による元音声の停止・取消は追加しない。通常返答・川柳・環境コメントを対象にする。

- 入力は既存の共通受付と一回のBERT分類へ進む。
- 生成・状態適用の直列枠は、確定した返答の配送前に解放する。文ごとの先行音声では全文受理時に解放し、元音声を続けたまま次の生成を始める。開始済みの保存は回収完了まで順序を保つ。
- 音声配送は既存の直列枠で順番を保つ。入力側が進んだ後の元音声にも取消所有者を保持し、表示ACKまたは実再生完了を既存履歴へ一度だけ反映する。
- 連続入力の固定返答は原入力・分類境界とともに保持し、既存の音声配送へ一件ずつ渡す。先の返答を後の返答で上書きせず、入力の再送でも新しい処理を取り消さない。
- 元音声の遅い完了は、新入力の状態・取消権・川柳の相談対象を書き換えない。
- 緊急警告、明示停止、voice off、接続・世界・サーバー終了は既存の取消条件を維持する。戦闘で中断した川柳返答は既存workerのまま再開する。
