## 変更内容

既存の `world_context.changes` に次の5種類を加えた。通常の呼びかけへの返答も、この共通観測を受け取る。

| kind | before / now |
|---|---|
| `body_self_position` | ドギドの足元のx・y・z |
| `body_player_position` | プレイヤーの足元のx・y・z |
| `body_self_orientation` | ドギドのyaw・view_yaw・view_pitch |
| `body_player_orientation` | プレイヤーのyaw・pitch |
| `body_player_visibility` | player_visibilityとreason |

元の `observations.body_observation` の現在値・前回値も保持する。値は受理済みの実測で、位置はblock、角度はdegree。近づいた／離れた、前後左右等の解釈を追加のモデル入力へ変換しない。視認は `visible / not_visible / unavailable` を区別し、見えない理由だけが変わった場合も差分にする。視認だけが未取得でも、有効な姿勢は利用する。

差分の所有者は既存の `conversation_observation::State`。各種類の**直近の変化一件**を保持し、身体分は最大5件。静止しても未考慮の変化は残る。beforeはその変化の直前に受理した観測であり、「最後に話した時点」や一連の移動の開始地点ではない。小さな浮遊・回転も厳密比較で差分になる。微小変化を間引く閾値は追加していない。

初回、身体の世代変更、失効、観測が途切れた後の再取得では古い身体差分を消し、新しい比較基準を作る。比較をリセットしてもrevisionは巻き戻さず、旧世代の返答完了通知で新世代の差分を消さない。生成中に届いた新しい差分は、以前のrevisionの完了通知では考慮済みにしない。

新しいプロンプト文・モデル呼出し・HTTP経路・自動発話の契機は加えていない。周期の環境通知が比較する項目は従来どおりで、身体の移動・向き・視認だけでは通知機会を作らない。別の環境変化による判断が完了した際は、その判断へ渡した共通観測全体のrevisionを考慮済みにする既存の扱いを維持する。

実装は `dogido-rust/src/conversation_observation.rs` とその `body_changes.rs`。通常返答への配線は既存の `dialogue/body_runtime` と `chat_prompt` を使う。
