## 受付範囲と確認した実装

| 項目 | この版の扱い | 主な根拠 |
|---|---|---|
| 平常のワークショップ | 句の完成後の感想・再読・推敲などは専用対話の入力として除外。通常会話から新しく一句を頼む入口は残す | `dialogue/haiku_runtime.rs`の`Workshop::open`、`dialogue/workshop_focus.rs`、`dialogue/submit.rs` |

| 乗れる動物 | 対応14種の呼び戻し意図。所有・装備・候補・着地点の条件は分類後に照合 | `assist/horse_recall/intent.rs`、`contracts.rs`、Fabricの`HorseRecallRuntime.java` |
| 最近の騎乗 | 接続・ワールドの範囲内で最近乗った1頭を保持する。全冒険・全乗車の永久履歴ではない | `HorseRecallRuntime.java`の`Scope.recentMount`とsnapshot更新 |
| 現在の敵 | 有無・位置・方角・距離・数・可視性の質問を敵情報とする | `combat/queries.rs`、`events/models.rs`の`VisualThreat` |
| 残りHP・過去の敵位置 | 自然な質問として残すが、現行の敵観測・永続検索では対応していない | 同上。playerのhealthをモブのhealthと混同しない |
| イルカ等の中立モブ | 攻撃している文脈なしに敵扱いしない。普通の位置・数の質問はother | Fabricの`observation/mobs/MobClassifier.java` |
| 身体視点・所持品 | 本人との方向・距離・可視性、所持品への自然な質問はotherとして残す | `body/contracts.rs`、`PlayerObserver.java`、既存の会話観測 |
| 自由な世界操作 | 建築、運搬、任意アイテムの持ち替え、攻撃の代行を実行済みとする文脈は修正。ユーザーが自然に要求する例は境界として保持 | 既存の限定操作契約・通常会話の範囲 |

上表のRustパスは`dogido-rust/src/`からの相対パス。確認した主要ソースのSHA-256は[manifest](../dev_tools/request_classifier/curation/2026-10-14-functional-scope/manifest.json)に保存した。今回本体の判定・実行コードは変更していない。

「通常会話の範囲に残す」は、その例の情報を常に回答できる、対象を必ず解決できる、操作が必ず成功するという意味ではない。現在の入力の意図と、観測・個体選択・実行可否を分ける。

## 未対応依頼43件の扱い

残りHP、過去の冒険の記録検索、しゃがみの観測、自由な移動・攻撃・建築・運搬、剣以外の持ち替え、対象外動物の呼び出し、将来条件の自動実行など。すべて正解は`other_request`のままで、`unsupported_request`タグを付けた。

延期や拒否だけの例、カテゴリを特定できない例まで機能外の具体的操作と決めつけない。たとえば「後でで大丈夫」は現在の提案の延期として通常会話に残す。タグ付けは例ごとの意味レビューであり、特定語の機械判定ではない。

`evaluation.summarize()`は`unsupported_request`と補集合`ordinary_scope`を件数・分母つきで集計する。この注釈はモデルへ渡らず、5分類を6分類にしたものではない。今後は全体の精度だけで、対応する操作と範囲外の依頼を取り違えていないかを判断しない。
