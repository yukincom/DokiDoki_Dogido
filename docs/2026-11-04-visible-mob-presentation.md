# 視認モブの提示を現在・直前へ分ける

通常会話と環境反応のモデル入力を、本人指定の見出しへ変更した。

元の提示は `nearby_mob_types`、`visible_hostiles` と、その `before / now`。変更後は次の形にする。

```text
## いま見えとるもん
- ゾンビ（2体）
- 村人（1体）
- アイアンゴーレム

## さっきまで見えとったもん
- パンダ
```

例の個数・種類は説明用。実際には既存の実視認だけから作る。非交戦のモブも「いま」に入り、同種の交戦相手がいる場合は別の数量として併記する。個体の水・地面・炎・名前などの詳細は既存の材料選別を保ち、視認由来の `basis` を「いま見えとる個体」と表示する。

- 話題選別・混雑時の省略より前に、現在見えている全種類を取り出す。辞書と個体詳細の絞り込みは引き続き行う。
- 「さっき」は、既存の未消費の種類変化・定期比較にある直前値から、今も見えている種類を除いたもの。新しい記憶・保持タイマーは作らない。過去欄に個数・位置・消えた理由は足さない。
- 現在の一覧が一部・未取得の場合と世界が変わった場合は、消失を推定しない。再視認した種類や、話題選別で省略した種類を過去欄へ送らない。
- 聴覚・嗅覚・同伴候補・カタログ知識だけを根拠に、視認欄へ追加しない。
- 元の観測台帳、変化検出、戦闘・川柳・操作・保存は変更しない。`nearby_mob_types` と `visible_hostiles` の元一覧は、この二経路の送信コピーから外す。

ゾンビと村人の同時視認を襲撃と確定する規則は追加していない。場面の理解と返答は、既存の一回の生成に任せる。

確認範囲は、視認と過去の分離・部分取得・再視認・話題選別・混雑時の保持、および通常会話／環境反応の送信本文。実モデルの理解改善とMinecraftでの発言は別途確認する。
