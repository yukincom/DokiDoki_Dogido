# look_player の返答から呼び寄せを選ぶ

2026-10-29。編集済み。本人指定のプロンプトへ更新。コンパイル確認成功。関連自動テスト38件成功（10月29日の結果と、30日の期待値修正後の再実行）。10月30日に本人から実機の来る／来ないの分岐成功を確認。

「こっちおいで」が共通BERTで `look_player` になると、従来は向き変更と返答だけで終わり、「今すぐ行く」と言っても移動していなかった。

## 接続

- 既存 `look_player` の向き変更成功から始める通常返答で、発話と `body_action.action = recall / stay` を一回で選ぶ。
- `recall` は既存 `body_requests.issue(Mode::Recall)` → Fabric → 身体Modの明示CALLへ渡す。移動・到着・危険時の制御は既存処理が所有する。`stay` は追加の移動命令を出さず、通常の身体制御は続く。
- 同じ入力世代・接続・返答turn・身体contextを実行前に再照合する。新入力・取消では古い返答も実行せず、能力消失・身体変更で受付できない場合は「今はそっちへ行けへんわ。」と返す。
- この返答だけは文ごとの先行再生を使わず、移動選択の受付後に全文を配送する。呼び寄せ用の別LLM返答は重ねない。
- 画像なし・撮影失敗でも、今回の原文と既存観測・履歴から同じ一回生成を行う。他の注視は従来の画像なし案内を維持する。
- 呼び寄せ命令と結果は元の注視結果とは別に同じ表示行へ記録する。`queued` は到着ではなく、既存 `succeeded / arrived` のACKだけで到着を確定する。
- 新しい分類ラベルや正規表現の呼びかけ判定は追加しない。通常会話・別の注視・workshopの出力からこの操作を実行しない。
- 欠損・未知の選択は移動しない。本文のJSON末尾補完を移動選択へ適用しない。これは通信外形の受信契約であり、選ばれた表現や意図を再審査するものではない。

## 追加プロンプト

正本: `dogido_server/llm/companion_prompts.json` の `look_player_contract`。当該返答だけ通常の発話JSON契約と差し替える。

> 今回の入力や会話の流れから、そばへ行くか向き直るだけかを選んでや。プレイヤーのところに行くなら recall、向き直るだけなら stay。返答と選択を同じJSONで返してくれや。
> JSON形式の例: {"action":"speak","speech":"ドギドのセリフ","body_action":{"action":"recall"}} または {"action":"speak","speech":"ドギドのセリフ","body_action":{"action":"stay"}}。黙るときはactionをsilent、speechを空文字にしてな。

## 確認結果

`player_approach_tests.rs` で共通受付の採用済みBERT結果・HTTP応答・身体ACKを模擬する。recall、stay、選択欠損、不正選択、画像無効、画像未取得、新入力、身体変更、能力消失、重複ACK、到着結果を確認する。`chat_validation` は完全JSONと本文補完時の操作抑止を確認する。既存の呼び寄せ・明示注視の試験も再実行する。

実行結果（同じテストの再実行は重複計上しない）:

失敗した既存 `recall_reply_starts_before_arrival_and_uses_the_existing_reply_prompt` は、`reaction_leaf/prompts.rs` が付ける身体観測の説明を期待文面に含めていない。今回の追加キー以外の共有プロンプト値と同ファイルは変更していない。10月30日の本人指示で共通本文＋身体観測説明へ期待値を更新し、同テストを含む6件の成功を確認した。受付中から到着後の台詞を生成する意図をコメントした。

実行コマンドは `./dogido-rust/cargo.sh test --lib --locked --offline --target-dir /private/tmp/dogido-part45-20261029/target <filter> -- --test-threads=1`。模擬HTTPのlocalhost待受はサンドボックス外で実行した。

自動試験はモデルの意味理解や実Minecraftの移動を証明しない。別の実機確認として、10月30日に本人から「ちゃんとこっち来るのとこないのとに分かれてた」と報告があった。呼び寄せの台詞は受付中から到着後の場面として準備する。実音声の到着タイミングの計測は行っていない。
