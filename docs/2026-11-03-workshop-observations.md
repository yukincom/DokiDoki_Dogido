# 川柳WS中の定期観測とプレイヤーへの注視（2026-11-03）

2026-11-03に書類側の本線へ採用。Minecraftの既存の会話取得で川柳の受付状態が `open` になった時だけ、Fabricは通常の定期撮影と周囲の収集を休む。掛け軸を隠しても受付状態は変わらない。

- WS中は地形・ブロック・一般モブ・環境音・匂い・所持品・乗用動物一覧の定期走査と、通常の身体画像の撮影・読み込みを止める。句集用の記録撮影と明示撮影は従来の扱い。
- 既存の周期通知で、プレイヤーの体力・足場や溶岩等への接触・空気量・ゲームの一時停止・敵との交戦・身体の姿勢を送る。`meta.workshop_observation` の付いた通知では未測定の項目を会話や次の句の材料へ登録しない。
- ドギドは既存の身体の注視経路で、プレイヤーが移動しても現在の目の位置へ顔を向ける。音声を切った状態でも同じ。視線のためのモデル呼び出しはなく、歩行や明示操作の優先順位は従来どおり。
- 終了・タイムアウトで軽量観測と注視を解除し、その次のtickで通常の観測を取り直す。本人の交戦や死亡は、サーバーから次の表示を受け取る前でも通常観測へ戻す。同じ句が戦闘後に再開すれば、相談中の扱いに戻る。

**実機での確認**　[通常起動と実機の確認手順](../dev_tools/実機確認_20261102/手順.md)でサーバーとModの両方を更新し、発句後の相談中にドギドの横へ移動する。向きが追従し、通常の身体画像が増えず、句の説明・変更・採用ができることを確認する。相談を終了し、再び身体が動くかしばらく静止したところで、通常撮影が戻ることを確認する。自動試験は定期通知・画像の受付／再開・身体への注視点配送・句の編集と音声を検証する。描画、聞こえ方、フレーム時間は実機で確認する。
