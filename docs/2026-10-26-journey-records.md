# 旅の記録と対話文脈の圧縮

2026-10-26。実装はRust本体と既存の本棚。検証結果は末尾に記載する。2026-10-27に[川柳終了後の20ターン条件を修正](2026-10-27-conversation-grounding-and-summary-threshold.md)。

## 冒険中の文脈

- 本人入力と確定応答の一往復を1ターンとして数える。冒険中の圧縮開始条件は、通常会話・川柳終了後とも未圧縮の完了対話が20ターン以上であること。直近の本文は80文字で切らない。
- 通常会話は20ターン揃った次の入力で、古い10ターンと同じ期間の共有済み出来事を、約40文字の冒険のあらすじへまとめる。元の本文は生成成功と入力世代・接続・元行の一致確認後に置き換える。
- あらすじは再要約しない。会話には直近5件だけを渡し、それ以前も冒険の記録用に元の順序・本文で保持する。
- 川柳の発句準備・相談・戦闘による相談中断の間は、対話圧縮を行わない。20ターンを超えた原文はメモリ上に保持し、モデルに読む範囲だけを直近20ターンへ制限する。専用相談履歴、通常会話、画像待機後の更新、環境反応、呼び寄せも共通の投影を使い、古い本文を再投入しない。
- WS終了後は読込制限を解除する。次の通常入力の生成前に完了対話が20ターン以上あれば、直近10往復より古い分を一回でまとめる。19ターン以下では要約せず、その後20ターンに達してから同じ処理を行う。川柳中に26ターンまで溜まった場合は、古い16ターンをまとめて原文10往復を残す。長さは10ターンあたり約40文字が生成指示上の目安。終了後に入力がなければ、サーバー正常終了時に未要約の完了ターン数で保存方法を決める。
- 未回答入力、単独の警告・出来事は補助枠40行。固定警告が連発しても完了した対話を押し出さない。沈黙や配送済みの川柳相談・記憶操作は文脈のターンに含める。通常雑談の直近3発話対だけを川柳材料に使う契約は変えない。
- 要約失敗・取消では原文を保持し、次の入力で再度一回だけ扱う。原文が20ターンを超えて残る場合でも、圧縮開始条件の20ターンは変えない。空応答・出力打切りを保存用のあらすじにしない。約40文字は生成指示で、文字数による切断や別モデルでの採点はしない。

生成先は既存の会話モデル設定。通常入力の直列枠内で未要約本文の圧縮を最大1回だけ追加し、その後に現在観測を取り直して通常の一回生成へ進む。OS AI・外部エージェント・ツール実行は使わない。

人が編集する指示文は `dogido_server/llm/history_summary.txt`。ドギドが関西弁で依頼する体裁とし、未記録の出来事や気持ちを補作せず、過去の記録を現在の観測として扱わない。今回の文面はユーザー確認済み。

## 終了と保存

接続ごとに一件の冒険を持つ。あらすじが確定した時点でもsnapshotを保存する。Minecraftの切断で先に接続が閉じた場合は、残りの対話をメモリ上でサーバー終了処理へ引き継ぐ。

SIGINT／SIGTERMによる正常終了では、会話・音声workerを止めた後、未要約の完了ターンが11以上なら一度だけ要約する。長さは10ターンあたり約40文字が目安。10ターン以下なら要約を呼ばず、原文を話者・出来事の種別付きで `raw_tail` に収録する。未回答入力は完了ターン数に数えず、その原文は短い記録に保持する。既存のあらすじは件数によらず全件そのまま保存する。11ターン以上の終了要約に失敗した場合は従来どおり未収録と記録し、確定済みのあらすじを保持する。

- 正本: `<memory_dir>/long_term/journeys/<journey_id>.json`
- 内容: 冒険の日付、開始・終了時刻、プレイヤー名、全あらすじ、短い未要約のやりとり、実再生／表示確認済みの句への参照、未収録情報。
- 記録メモ: `<memory_dir>/bookshelf/state.json` の `journeys`。あらすじの更新で上書きしない。
- 本棚の一覧: 年月日と開始時刻（24時間表記・分まで）、あらすじ（なければ未要約本文）の最初の「。」までを表示する。日時1行＋本文最大2行で、全体を3行以内に収める。詳細でも開始時刻を表示する。
- 装丁: 句集・あんちょこと同じ紙色・枠・文字サイズ。左側は辛子色で、旅の表紙画像は置かない。
- 本棚: 既存の `GET /api/library` と `PUT /api/library` を使う。メモの保存は既存revisionで競合を検査する。
- 句リンク: 既存の出所付き句IDを使う。削除済み・未保存などで句集に存在しない場合はリンクを作らず、その旨を表示する。

記憶設定が無効な場合、旅の記録は保存しない。preview・テキスト相談室も冒険として収録しない。強制終了・電源断は最終処理が走らないため最後の保存済みあらすじまでとなる。評価用 `eval/episodes.jsonl` は旅の記録へ保存／読み戻ししない。原文は正常終了時の短い未要約分だけを収録し、通常の会話全文ログは作らない。保存した旅の記録を次の接続の会話へ自動注入しない。

## 非公開保管

あらすじ・未要約本文・日時・発句リンク・記録メモは、既存の非公開データリポジトリへの明示アップロードに含める。旅の記録メモの下にも、句集と同じ送信ボタンを置く。未保存メモがある間は先に保存する。

`journeys/<ID>/snapshots/<内容hash>.json` にその時点の記録とメモを保持し、`index.json` の `journeys` が最新版を指す。メモだけの変更や冒険終了時の追記も差分として送り、古いsnapshotとローカル正本は残す。一句もない旅も保存対象にする。既存の研究保存先が設定済みで利用可能であること、送信先が非公開であることの検査は維持する。

公開モードではRustの書出し段階で旅を含めない。公開投影も従来の句・J-lens・内部表現の許可項目だけを使い、旅のID・あらすじ・未要約本文・記録メモを含めない。旅やメモだけの変更では公開データも変化しない。送信先の公開範囲や既存設定は変更しない。
