# 2026-10-12 Qwen3.8 Flash Next 125B / Gemma 4 26B 川柳比較

125BはJSON川柳の9回計測を完走した。ただし現構成では、Gemmaより採用数と厳密5・7・5が少なく、全試行の所要時間も長かった。MTP内部エラーが発生しているため、この結果を125Bモデル単体の能力差とは断定しない。

## 比較結果

集計対象は各9回。ウォームアップは除外。Gemmaは前回の保存結果、125Bは今回の計測結果であり、同時期に取り直した比較ではない。

| 項目 | Gemma 4 26B-A4B | Qwen3.8 Flash Next 125B |
|---|---:|---:|
| 構成 | QAT MLX 4bit | GSQ-RCO IQ3_XXS + MTP Q8_0 |
| 川柳検査で採用 | **9/9** | **6/9** |
| 厳密な5・7・5の採用句 | **9/9** | **0/9** |
| 全9回の所要時間・中央値 | **4.033秒** | **10.079秒** |
| 全9回の所要時間・平均 | 5.462秒 | 11.113秒 |
| 所要時間の範囲 | 3.838–9.605秒 | 3.046–22.898秒 |
| 採用された回だけの中央値 | 4.033秒 | 4.953秒 |
| 再生成回数・平均 | 0.44回 | 2.67回 |
| API呼出し数 | 26 | 51 |
| HTTPエラー | 0 | 0 |
| 候補JSONの解析成功 | 13/13 | 33/33 |
| 候補の出力token上限による打切り | 0 | 0 |

既存コードは各行の音数±1を許容する。「採用」は厳密な5・7・5や日本語の自然さを保証しない。所要時間は生成、コード検査、根拠評価、再生成、Python補助の起動を含む。全9回の統計には125Bの不採用3回も含む。

| 場面 | Gemma 採用 / 厳密5・7・5 | 125B 採用 / 厳密5・7・5 | 中央値 Gemma → 125B |
|---|---:|---:|---:|
| 草地・青空・柵・卵 | 3/3 / 3/3 | 3/3 / 0/3 | 6.881秒 → 3.714秒 |
| 暗い坑道・松明・石炭 | 3/3 / 3/3 | 3/3 / 0/3 | 3.883秒 → 6.192秒 |
| 夕暮れの雪斜面・金床 | 3/3 / 3/3 | 0/3 / 0/3 | 3.989秒 → 16.841秒 |

125Bの雪斜面は3回とも6回の再生成後に `max_regeneration_rounds` で不採用。主な検査理由は意味不保持、日本語の不自然さ、音数超過、同じ候補の再提示だった。

## 全9回の句比較

同じ場面・同じseedの組。原文を維持し、三行の区切りだけ「／」で表記する。125Bの雪斜面3件は採用句がないため、検査ログの最終候補を不採用と明記して載せる。Gemmaは全9回が採用・5・7・5。

| 場面 / seed | Gemma | 125B | 125Bの結果 |
|---|---|---|---|
| 草地 / 101 | あおぞらと／フェンスのそばの／たまごある | あおぞらに／オークのさく／くさちの ひ | 採用・5/6/5 |
| 草地 / 202 | あおぞらと／フェンスのそばの／たまごある | あおいそら／オークのほのまに／たまごひとつ | 採用・5/8/6 |
| 草地 / 303 | あおぞらと／フェンスのそばの／たまごある | あおぞらに／おーくのふぇんすと／たまごならぶ | 採用・5/8/6 |
| 坑道 / 101 | ともしびが／くろいこころを／みつめるよ | やみのかね／まつのほのおは／ほねはこなに | 採用・5/7/6 |
| 坑道 / 202 | ゆらぐひが／くろいこころを／てらしだす | やみのかね／まつのほをくろい／ほねのこな | 採用・5/8/5 |
| 坑道 / 303 | ゆらぐひが／くろいこころを／てらしだす | やみのなか／まつのひが じっと／くろい いし | 採用・5/8/5 |
| 雪斜面 / 101 | ゆうぐれの／しろいしずけさ／てにのこる | ゆきのななめ／かなはつめたい／よるのそらに | **不採用・最終候補** |
| 雪斜面 / 202 | ゆうぐれの／しろいしずけさ／てにのこる | ゆきのかた／かなてにかな／ゆうやのつめ | **不採用・最終候補** |
| 雪斜面 / 303 | ゆうぐれの／しろいしずけさ／てにのこる | ゆきのけもの／かななてにふえる／ゆうやのつめたい | **不採用・最終候補** |

不採用3件の最終検査理由（実際の検査ログに基づく）：

- 雪斜面101：「かなはつめたい」の「かな」が金床や雪の材料に対応せず、意味が不明。同一候補の再提示も記録。
- 雪斜面202：「かなてにかな」が意味を説明できない造語で、日本語として不自然かつ材料の意味に対応しない。同一候補の再提示も記録。
- 雪斜面303：「かななてにふえる」に対応する材料がない。下五「ゆうやのつめたい」は音数超過。同一候補の再提示も記録。

句そのものの目視所見：

- Gemmaは全9句が5・7・5で、日本語としてまとまっている。草地は説明的、坑道は「くろいこころ」の比喩、雪斜面は「しろいしずけさ」「てにのこる」で場面の感触を表す。ただし草地と雪斜面は各3回とも同じ句で、変化は少ない。異なる採用句は全9回で4句。
- 125Bは候補の変化が多い一方、「オークのほのまに」「まつのほをくろい」など意味や文法を取りにくい表現が採用されている。雪斜面では意味が不明な語が修正後も残った。採用6句もすべて厳密5・7・5から外れている。
- これは盲検採点ではない。生成と根拠評価の両方に各モデルを使うため、検査の甘さも採用率へ影響する。MTP内部エラーがあるので、125B本来の日本語能力にそのまま一般化しない。

## 実行・メモリ上の問題

- 全53 HTTP要求（ウォームアップ2 + 本計測51）は成功。要求のtemperature、seed、token上限、thinking offを保存した実通信で照合した。toolsとresponse_formatは未使用、reasoning本文なし。
- llama.cpp側の完了task数も53で一致。ドギド本体、マイク、Minecraft、モデル取得・ビルド・検証処理は停止して計測した。既存のGradle待機プロセスは残っていた。
- **MTP内部エラーあり。** ウォームアップ込みで `decode: failed to initialize batch` が52件。その内訳はdraft側37件、`mtp_flush: deferred catch-up failed rc=-1` が15件。sequence位置不整合と `Drafts may degrade` の警告もある。HTTP成功とは別の問題であり、出力品質への影響・根本原因は未確定。MTPを外した対照実験や実装修正は行っていない。
- 5秒周期の計28サンプルでメモリプレッシャーはnormal 11回 / warning 17回。criticalは観測しなかった。開始前21,961.75MiB、終了後23,787.75MiBのswap使用で、増分は**1,826MiB（約1.78GiB）**。同区間のswap-outは約2.09GiB、swap-inは約0.33GiB。いずれもOS全体の値であり、以前からあるswap約22GBを125Bだけの使用量とは扱わない。
- 計測後に125Bを既存管理手順で停止。8080・5055のlistenerなし、125B PIDの終了、メモリプレッシャーnormalへの復帰を確認した。27Bはユーザー指示により計測しない。

## 揃えた条件と限界

- 前回の保存版JSONバイナリ・入力3件を使用し、参照するソース503ファイルもSHA-256で一致確認。現行本体への変更は混ぜていない。
- 草地seed 7を集計外ウォームアップ。草地→坑道→雪斜面、それぞれseed 101 / 202 / 303、逐次実行。
- 候補300 / 根拠評価512 tokens。temperatureは初稿0.6 / 再生成0.3 / 根拠評価0.0。seedは元の段階別offsetと連番規則。再生成最大6回。
- API 20秒、一句180秒、外側190秒。場面準備、TTS、ゲーム配送、記憶保存は計測外。
- 125Bは配布元49パッチ適用のllama.cpp、MTP、context 16384、parallel 1、reasoning off。起動は既存 `server.py switch 125b`。起動設定・実PID・開始時刻・cwd・実行ファイルhashを保存。
- GemmaはMLX、125Bはllama.cppで、量子化、モデル固有テンプレート、キャッシュ、明示していないsampling既定値は異なる。今回はJSONのみなので前回のnative方式との交互実行もない。**同じ川柳処理条件での構成比較であり、モデルだけを変えた厳密比較ではない。**
- 完全な起動前メモリ記録は取得できず、最初の完全な環境スナップショットはモデル読込み後・推論前。Minecraft終了確認時のJava判定を、待機中Gradleも含む判定からMinecraft実行クラスによる判定へ修正した。追加のモデル要求やウォームアップのやり直しはない。
