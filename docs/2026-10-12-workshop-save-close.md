# 川柳相談の保存・終了案内の修正

2026-10-12。状態: ユーザーのプロンプト確認後、書類側mainへ実装。Rust全体667件・模擬通信44項目・Clippy・通常起動用ビルド・非起動preflight成功。実Gemmaで報告された保存・終了の流れは成功。追加試験で見つかった想起への誤配送も、workshop中の過去句検索を止めて解消し、同じ表現で終了を確認した。感想から変更案を出力する問題は残る。稼働中本体は再起動していない。

## 実際に起きたこと

対象の句「ゆうぐれの／ぴんくがゆれる／たびのあし」は発句時に保存されていた。
「豚のピンクと夕暮れのピンクの空と合ってる気がする」という解釈への返答で、モデルが「ピンクの空」を差し替え案として抽出・保持した。その後の「これはこのまま保存しよう！」には、現在句の保存確認でなく `stage_conversation_candidate` と `purpose:adopt_pending` を返し、操作と目的の不一致で二度とも不成立になった。案への変更や新たなrevision保存は行われていない。

「この句はこれで完成だと思う！」「では終了で！」には、モデルは `close_workshop` と `purpose:finish_workshop` を返したが、`confidence` と今回の原文 `evidence` を省略した。既存検証で不成立となり、再試行をしない現行方針に従って元の返事だけが使われ、内部はopenのまま残った。生のモデル応答を稼働中本体の読み取り用snapshotで確認した。言い回しの固定判定や音声認識の失敗ではない。

## 修正内容

- 本体の保存成功後のentry/revision ID、またはテキスト相談室の保存句への接続から、現在句の保存確認を `current_verse_saved` として既存の相談文脈へ渡す。未採用案・相談中の案・単独試験の仮IDを保存済みとは扱わない。
- モデルへ、現在句をそのまま残す依頼と相談案を採用する依頼の区別を案内する。保存確認済みの現在句は既存のrespondで応答し、重複保存の経路を足さない。
- 解釈・連想・感想を差し替え案として保持しないよう、既存の編集案内を明確にする。
- 終了に必要な項目は既存の共通説明へまとめ、正しい返答例を添える。特定の終了語による自動判定は追加しない。
- 終了不成立時の元の理由と契約エラーを診断ログへ残す。会話履歴・モデルへの次回入力へ戻さない。

原文の根拠、confidence、否定・疑問・引用・条件、pending、句の版と保存結果の検証は維持する。単独終了の再試行は追加しない。

## 確認済みのプロンプト差分

### 保存状態と対象

current_verse_savedは現在句だけの保存状態や。trueで現在句をそのまま残すよう頼まれたら、respondで保存済みと伝えてな。falseまたは項目が無いときは、保存済みと断言せんといてな。

### 終了の必要項目

close_workshopの例: {"action":"close_workshop","purpose":"finish_workshop","confidence":0.95,"evidence":"今回はここまでにしよう","speech":"うん、また話そな。","checks":[]}。例のevidenceは、今回の認識原文に置き換えてな。

### 相談案の保持

句の意味・情景の説明や連想、感想だけならline_proposalは付けんといてな。

### 残件

1. **対応済み（下記追記）**。`recall_query.rs` の既存 `requested` は「句」と「今日」の共起だけでも想起要求とする。workshopでこの判定が現在句の相談を奪っていたため、open中は過去句検索を実行しない仕様に変更した。検索条件そのものは今回変更していない。
2. 感想への実応答には、追加指示に反して `line_proposal` が含まれた。今回は原文にないひらがな表記の置換語「ぴんくの空」を返した案が保持されず、正本も変わらなかった。モデルが感想と変更案を安定して区別できた証拠とはしない。この指示の効果と「保存済み」と明言する文面は未達。

実Minecraft・実マイク・実音声の確認は未実施。通常起動用ビルドは更新済みだが、稼働中プロセスはそのまま。既存本文のその他の重複指示も今回の修正には含めていない。

## 追記: workshop中の過去句検索を停止

同日のユーザー提案に合わせ、workshopが開いている間は明示的な想起依頼でも過去句検索へ渡さない。現在句・未採用案・対話を読む既存の共同編集へ渡す。一般知識DBの照会、明示保存、lesson解除には変更を加えていない。

- `dialogue/workshop_runtime.rs` の、共同編集より先に過去句検索へ送る処理と、そのためだけの読み辞書取得を除いた。
- `dialogue/chat_runtime.rs` も、既存のコード確定済み `poem_reference.open` と `workshop_fallback` を使って検索を止める。共同編集が通常会話へ渡した場合や、戦闘pauseでworkshop用の入力文脈がない場合もopen状態を尊重する。新しい検索経路や語句別の終了判定は追加していない。
- 相談を閉じた後の「覚えてる句を教えて」は従来どおり保存済みのentry/revisionを読む。未採用案は保存・想起対象に昇格させない。
- この追記の実装ではプロンプトを変更していない。
