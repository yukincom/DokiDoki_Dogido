# 川柳データ採取中の一時設定

**状態:** データ採取中のみ有効。採取終了後に通常設定へ戻す。

2026-10-18から、川柳データ採取のため次の一時設定を使う。

- 自動発句の間隔を **4分（240,000 ms）** にする。同日、7分では長かったため短縮した。workshop中の時間は数えず、workshopが閉じた時点から次の発句までを数える。ゲーム一時停止中・学習中・Web調査中も発句時計を止める。
- クリエイティブモードでの採取中は、敵対モブの視認・スキャンだけでは川柳やworkshopを中断しない。
- 被弾直後、敵対音、明示された戦闘状態、緊急警告、ゲーム一時停止など、視認・スキャン以外の割り込み条件は引き続き扱う。

## 採取終了後に戻す

採取を終えたら、次の二点を戻す。

1. `dogido-rust/src/dialogue/workshop_focus.rs` の `TEMPORARY_ALLOW_SCANNED_HOSTILES_FOR_SENRYU_COLLECTION` を `false` にする。コードと説明コメントは残す。
2. `.env` の `DOGIDO_HAIKU_INTERVAL_MS=240000` を削除する。通常の既定間隔は10分（600,000 ms）。

通常設定へ戻すと、敵対モブの視認・スキャンも従来どおりworkshop中断の対象になる。

この一時設定は次回起動時に読み込まれる。稼働中のプロセスには自動反映されない。
