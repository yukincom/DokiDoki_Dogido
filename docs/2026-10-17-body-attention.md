# 身体の注意範囲と対象への集中（0.7.7）

2026-10-20追記: 安心度に応じた注意範囲と発話・行動の統合は[後継仕様](2026-10-20-reassurance.md)へ移行。以下は0.7.7当時の記録。

状態: 前方8ブロックへの拡張をmainに実装・adapter導入済み。adapter全199件成功・配布JARビルド成功。Minecraft再起動後のゲーム内確認は未実施。

[0.7.6の追従](2026-10-17-body-vertical-follow.md)を継続し、探索の範囲と間を次のように変更する。

## 動作

| 状態 | 周辺への注意 |
|---|---|
| 安全なFOLLOW待機・見回し | 前8・後ろ1・左右2・上下3ブロック |
| 距離追従・呼び寄せ中 | 各方向1ブロック |
| 初回・追従完了直後 | 3秒間、各方向1ブロック |
| プレイヤーが速く移動した後 | 最後の速い移動から3秒間、各方向1ブロック |
| 観察移動の配送受付〜移動中 | 選んだ個体／ブロック一件だけ |
| 対象に実到着 | 5秒間その対象を見て、終了後に現在位置から再探索 |

範囲は身体の眼を中心にした距離で、水平は身体のyawと一緒に回り、上下は世界の鉛直を使う。指定の後方や上下も含むため、近傍注意には旧前方120度・垂直90度のFOVを重ねない。既存の遮蔽rayで見通せる対象だけを取得する。壁、未ロード範囲、見失った対象を過去の座標で補完しない。

プレイヤーの速い移動はserver tick間の実移動が5ブロック/秒を超える場合。通常歩行やカメラの回転、身体の浮遊では待ち時間を延ばさない。身体Modが実到着から100tickを計り、adapterの結果受信時刻から5秒を加算しない。

Rustの対象選択は開始時刻から最短3秒間隔。会話・危険・追従・到着後待機・実行中の命令による保留は継続する。見回しだけを理由に選択やMOVE_TOを拒否しない。選択結果の現在視認・同一個体・距離・安全性を再照合し、受理時に既存のinspect処理で見回しを止める。生成中に対象が見えなくなれば実行しない。

## 接続と保持

- 既存の身体collector・BodyVisibility・body_interest・inspect_body_target・BodyBridgeのMOVE_TOを使う。新しい操作経路やモデル呼出し、プロンプトの変更はない。
- 近傍の非敵対モブ・ブロック等は注意範囲に従う。owner視認・敵の取得範囲、聴覚・嗅覚・接触状態、危険回避と衝突検査は既存の経路を維持する。敵と近傍のrayは同じ4096本の予算を共有する。
- 集中対象はadapter接続内だけに保持する。context・命令ID・sequenceが一致する結果を使い、到着後も身体の`inspection_dwell`が終わるまで保持する。配送失敗、失効、危険回避、追従、呼び寄せ、無効化、別の身体世代では解除する。
- 集中を設定・解除した同tickでも古い全候補を返さないようframeキャッシュを無効化する。遮蔽・対象消失時は候補0件で、別対象へ勝手に切り替えない。
- 種類の既見、対象別の120秒再訪待ち、直近選択は維持する。範囲が閉じていたものを毎回「初めて見た種類」へ戻さない。モデルは既見も選べるほか、`stay`も選べる。3秒ごとの移動を強制しない。
- Body API v7、HTTP姿勢v3・自律制御v1を継続する。対応adapter buildは`2026-10-17-body-attention-front8`。

## 検証と導入

自動検査は向き付き範囲の境界、遮蔽・未取得、個体／ブロックへの集中、実到着・配送待ち・失効の区別、3秒の選択間隔、5秒の実到着後待機を扱う。ゲーム内の見た目とモデルがどの対象へ行くかは別に確認する。

身体Mod 0.7.7、対応adapter、更新したRust通常起動用バイナリを揃え、Minecraftとドギド本体を再起動する。変更前の差分・対象ソース・検証記録は各変更のcheckpointへ保存する。前方8ブロック版の記録と直前1世代のModバックアップは`.dogido_tools/checkpoints/2026-10-17-body-front8/`で管理する。

Minecraft終了後に旧Modをバックアップし、身体Mod 0.7.7と対応adapterを導入した。配布物と導入先のSHA-256一致、他のModが変わっていないこと、Rust起動用バイナリが最新のソースを含むことを確認した。再起動は利用者が行う。

検証時、通信fixtureに旧adapter build名だけが残っていた1件を更新して全体再検査した。集中はHTTPセッション失効時にも解除し、同じマスの別種類のブロックを選択対象と取り違えないことを検査した。Body APIの37クラスは0.7.6とバイト単位で一致している。

前方だけを3から8ブロックへ広げる。後ろ1・左右2・上下3、遮蔽、追従中の各方向1ブロック、選択の最短3秒間隔と実到着後5秒の集中は継続する。変更はadapterの注意範囲に限り、身体Mod 0.7.7・Rust・プロンプトは共通。境界8.0/8.001、yaw回転、遮蔽を既存の検査で確認する。
