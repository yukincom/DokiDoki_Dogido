# 2026-10-11 坑道推定を実測材料へ置き換える

## 原因と変更

Y=112の観測でも、同じXZ位置の地表Y=119から深さ7と計算され、空が見えない・頭上は土・屋内設備なしという条件で、コードが「坑道らしい地下空間」を作っていた。これはMinecraftの構造物判定ではなく、本体独自の推定だった。川柳には事実扱いの出典として渡り、説明にも使われていた。

- 環境投影から `LikelyPlace` と天井材質・深さ・屋内設備による坑道推定を撤去。
- 通常会話・環境反応は既存の共通観測で、空の可視性と頭上材質を受け取る。根拠のない「地下っぽい」「屋根のある空間」も補わず、「空が見えない空間」とする。実測に基づく木陰、家・拠点、洞窟バイオーム等の既存情報は維持。
- 川柳は既存の見どころ・出典経路で「空は見えず、頭上に土／石／鉱石がある」を渡す。観測材料の修正であり、モデルによる自然な解釈・表現を禁止する仕様ではない。
- 実際の地形ブロック破壊と道具に基づく「採掘中」は行動として保持し、場所を「地下」と決めつけない。
- 構造物として観測された `mineshaft` の「廃坑」情報は保持。過去に保存された句・出典は書き換えない。

モデルへ別経路や禁止語検査を追加せず、入力材料を修正した。QATの能力が今回の原因だったかどうかは比較実験で確認していない。

## 確認状況

ユーザー確認後に `./cargo.sh test --all-targets --no-fail-fast --locked --offline` と `./cargo.sh clippy --all-targets --locked --offline -- -D warnings` を実行。

| 対象 | 結果 |
|---|---|
| 今回の回帰テスト | 4成功。Y=112・地表との差7、低いY／深さ欠損、土・石・鉱石、天井未検出、実破壊による採掘、観測構造物の廃坑を確認 |
| 環境投影・場所投影 | 環境2,277ケースと場所3,386ケースの比較成功。入力fixtureは変更せず、撤去した推定に関係する期待値だけ更新 |
| Rust全体 | 638成功・6失敗。lib 512、main 2、統合17対象 124成功・6失敗。example 13対象はコンパイル済み、テスト件数0 |
| Clippy | 既存と同じ17指摘。指摘本文・場所の追加なし |

6失敗は変更前と同じ会話policy・森林注記・ポータル注記の期待値不一致で、失敗名と比較内容が同一であることを確認した。各失敗関数内では最初のassertで停止するため、その先のケースまで成功したとは扱わない。今回追加したテストの初回コンパイル時に、読み取り専用イベントへ直接代入する誤りがあり、JSON入力から組み立てる形に修正して再実行した。

通常会話の共通観測と川柳の出典に実測材料が渡り、廃坑の構造物情報が保持されることを自動確認済み。LLMの実応答、release版の更新、常駐本体の再起動、Minecraftでの再確認は未実施。

変更前の復旧点は `f05d1a4`。検査ログは一時ディレクトリ `dogido-observed-terrain-20261011` の `rust-tests-verified.log`、`clippy.log`、`verification-summary.json`。

変更前の全体検査は [コミット整理前の全体検査](2026-10-11-checkpoint-verification.md) を参照。そこで記録した既存6件のfixture不一致とClippy 17指摘は、この変更で解消した扱いにしない。
