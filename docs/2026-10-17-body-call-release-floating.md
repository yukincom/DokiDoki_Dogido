# 呼び寄せ後の解除と紙風船のような浮遊

後継: 現在の追従距離・上下移動・寄り道間隔は[0.7.6の記録](2026-10-17-body-vertical-follow.md)。以下は各版の実装・導入時点の記録です。

日付: 2026-10-17
状態: 身体Mod 0.7.5の実装済み。全126件成功（失敗・除外0）と配布ビルドを確認済み。Minecraft終了確認後に導入済み。ゲーム内確認は未完了。

## 変更理由

ユーザーの「call後に正面へ張り付く」「来た後は普段の動きに戻っていい」「通常の動きも、ガタガタではなく紙風船のようにふわっと上下してほしい」に対応する。

既存CALLの到着後も現在の正面へ追い直す保持処理を取り除き、既存の浮遊処理を移動・待機共通で調整する。

## 動作

- CALLは現在の安全な目標から0.2block以内、かつownerとの水平距離が`callDistance`以内に入ったtickで成功を一度だけ返し、直ちにCALLを解除する。次tickから元のmodeの通常動作へ戻る。
- 到着後のカメラ回転や小移動では再接近しない。FOLLOWの待機・見回し・観察選択を再開でき、通常の距離追従も引き続き働く。意図のない新しい観察行動を強制はしない。
- 未到着のCALLは現在ownerの位置・向き・作業を追い直し、既存の400tick期限・安全検査・採掘正面回避を使う。危険回避中や安全な候補なしでは成功にしない。
- 移動・待機の両方に振幅0.18block、周期120tickの正弦波を重ねる。通常20TPSでは約6秒で一往復し、上下の端で滑らかに減速・折り返す。
- 基本移動は進捗と速度の連続性で選ぶ。距離そのものの加点で、開けた水平移動にも余分な上下候補を選んでいた点を直した。
- 基本移動と浮遊を分け、移動目標は現在の波の高さに合わせる。慣性には基本移動だけを渡し、浮遊を次tickで二重に増幅しない。
- 位相補正した目標と、そこへ向かう基本移動の次の位置も空間・危険を再検査する。低い天井等で入れない場合は元の目標への移動へ戻し、そのtickの浮遊を休止する。
- 浮遊を加えた移動にも既存の生体衝突・ロード範囲・危険経路・作業正面・最終位置の空間検査を適用する。追加できない場合は安全な基本移動を保ち、波の位相も止める。一部の上下差分だけを捨てて高度が累積することを防ぐ。
- 退避・埋まりからの復帰・安全目標なしでは浮遊を休止する。埋まり復帰先には波の高低差と到着慣性に必要な余白を取る。

## 検証と導入

- Body API v7を継続。adapter・Rust・分類器・プロンプトの変更はない。
- 自動検査ではCALL即時解除と成功の一度通知、到着後の回転・小移動、通常観察の再開、動くownerへの接近、複数の波の位相と採掘回避、通常FOLLOWの到着を確認する。
- 実際の移動計算で、移動→待機→移動の波、速度と加速度、長時間の高度非累積、波が繰り返し止められる場合、天井・生体衝突、埋まりからの復帰を確認する。
- 自動検査とビルドは、Minecraftでの見た目・体感・実通信の確認とは分ける。
- 変更前のHEAD・差分・対象ファイルと今回の差分は`.dogido_tools/checkpoints/2026-10-17-call-release-float/`に保存する。別作業の未コミット変更をまとめたコミットは作らない。

実機では`/dogidobody call`で来た後に視点を回し、小さく移動しても正面へ貼り付かないことを確認する。待機・通常追従・観察移動で、揺れが急な上下ではなくゆっくり見えるかも確認する。
