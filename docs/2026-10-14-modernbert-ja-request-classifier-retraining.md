- 両候補ともseed 42、学習率 `2e-5` / `5e-5`、各10 epoch、batch 16、最大128 token、AdamW、weight decay 0.01、linear scheduler、warmup 0。MPS GPU / float32 / SDPA、CPU補助4スレッド。依存ライブラリ版も同一。

## 検証と解釈の限界

- データ・評価補助の全11テスト成功。新旧8組の予測について、scikit-learnで正解率、macro-F1、分類別precision/recall/F1、support、混同行列を独立再計算して一致を確認。予測行とデータのID・本文・履歴・正解、およびモデル・コード・データのハッシュも照合した。
- 前回のtest・回帰の誤分類を見た後で追加データを設計・選別している。今回の実行内ではdevだけで選択しているが、固定評価セットへの反復開発であり、未見データへの汎化の証明にはならない。
- seedは1つ、testは75件、回帰は40件。2問・1問の差を再現性のある改善・悪化と断定しない。複数seed、追加元別の切り分け、新しい評価セット、実音声・実ゲームは未評価。
- 履歴ありtestは21→23件正解だが、devの履歴ありは22→21件で、同一発話の対照例も残る。複数発話の履歴例を追加したこと自体を、長い会話への汎化成功とは扱わない。
- 未校正のsoftmax値は誤りでも高い。犬の呼び戻しの誤分類は約99.995%で、閾値を上げるだけで解決するとはいえない。
