> keep_memory は、今までの冒険で心に残った過去の記憶や。そこにある物・状態は、記録された時のもんで、今も目の前にあるとは限らへん。
> 今の観測は observations、変化は changes の before から now として読んでな。今の状態は最新の observations を使って、過去の記憶を思い出すときは、過去のことやと分かるように話してな。
> 現在の観測が不明なら、keep_memory で埋めず、分からんまま扱ってな。

## 解釈と未検証の範囲

今回の小規模試験では、現在観測・チェンジ・過去記憶を別欄にし、過去の記録だと明示する構成は試作を進める根拠になった。ただし、現在観測が明確な合成場面が中心で、時制区別の信頼性を保証する結果ではない。
