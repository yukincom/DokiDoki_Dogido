# 複数の既存モブ資料から画像の種類を選ぶ比較 — 2026-10-31

**普段のモブ説明データを8候補ぶん添えても、今回の画像ではゾンビ・アイアンゴーレムの識別改善は確認できなかった。カメと原寸のオウムは選べたが、候補名だけでも選べたため、説明データ独自の効果とはいえない。**

ユーザーの追加依頼「dataでいつも渡しているmob情報を複数提示して、その中から正しいmobを選べるか」に対する独立実験。前回の6場面・2解像度に、名前だけ／既存資料付きの2条件を対にし、24要求を既存ローカルGemmaへ送信した。各条件1回。新しい撮影、本体・設定・データ正本の編集、戦闘への組込みはしていない。

## 実際に添えたもの

正本は `data/catalogs/entries/mobs/{hostile,neutral,passive}.json`。本体の `catalog_knowledge::mob` → `prose` と同じく、`label`を表示名に分け、読み・出典・priority・threat_class・dogido_tactics・職業別定義等を除き、それ以外の記述はそのまま `general` に保持した。外見タグだけを抜き出したり、新しい特徴を加えたりしていない。村人の職業と年齢は観測していないので、特定職業・子供の上書きは選んでいない。

| 全画像で共通の候補順 | 既存のvisual_tags（説明の一部） |
|---|---|
| スケルトン | 骨、弓、白い |
| カメ | 甲羅、浜辺、ゆっくり |
| エンダーマン | 黒い、長身、紫の目 |
| 村人 | 日常、村 |
| クリーパー | 緑、無言、４本足、虚のような顔 |
| オウム | 羽色、小さい嘴、肩のり |
| ゾンビ | 腐敗、緑、腕をのばす |
| アイアンゴーレム | 鉄、巨体、つる草 |

ほかに元データの音・動作・場面・感情・役割・環境特性も含む。[送信資料全文](catalog-data.json)・[正本パスとhash、除外項目](source-manifest.json)。カタログは会話・表現のための一般資料でもあり、村人の大きな鼻や組んだ腕、カボチャで隠れたゾンビ頭部などの識別説明を今回書き足したものではない。失敗原因をこのデータの内容だけに特定したわけでもない。

**名前だけ条件は、同じJSONの `general` だけを空にした。** system、質問、候補名・ID・順序、usage、画像のbytes、生成設定は同じ。候補一覧は陰性画像とプレイヤー画像にも同じものを付けた。各候補の `basis=[]` とし、観測済みという偽の印や真のentity ID、正解の場所は渡していない。種別IDは全候補の識別子としてのみ提示した。

「一覧に載ることは存在の証拠ではない」と指示し、「プレイヤー」「候補外」「種類不明」「生き物を確認できない」も許可。複数写る場合は複数回答できる。指示全文は実行前にチャットで示し、資料を含む全文を固定した。[プロンプト全文](PROMPT_PREVIEW.md)・[24要求のプレビュー](request-previews.json)・[実験条件](conditions.json)

## 結果

位置と特徴を実際の対象へ対応づけて評価した。正しい種類名だけが含まれていても、根拠の対象が曖昧なら完全な識別成功とはしない。

| 画像・正解 | 名前だけ・192px | 既存資料付き・192px | 名前だけ・原寸 | 既存資料付き・原寸 |
|---|---|---|---|---|
| [01 カボチャ姿のゾンビ](../images/case_01_native.png) | **ゾンビを選択**。ただし根拠が「青っぽい肌」で不正確。3.045秒 | **種類不明**。橙色の頭だけを説明。2.909秒 | **プレイヤーと誤認**。2.788秒 | **プレイヤーと誤認**。2.604秒 |
| [02 村人＋ゴーレム](../images/case_02_native.png) | 「村人」。青い服・中央という対象対応が曖昧。ゴーレムなし。2.427秒 | 同じく村人との対応が曖昧。ゴーレムなし。2.902秒 | 村人2人と回答するが位置・服の説明が混在。ゴーレムなし。2.745秒 | 「青い服・長い鼻の村人」。対象対応が曖昧。ゴーレムなし。2.898秒 |

06の種類選択はプレイヤーだが、人物の同一性・視点まで正しく認識した意味ではない。

**前回からの違い:** 192pxのゾンビは、候補なしの4点質問で「エンドマン」、今回の名前だけで「ゾンビ」、資料付きで「種類不明」。候補名と選択を促す質問で正解名が出た一例はあるが、名前だけでも画像の根拠は弱い。資料付きが一貫して優れる結果ではない。原寸のオウムは前回の4点質問でも識別できており、今回の資料によって新しく解けたものではない。[前回結果](../RESULTS_REVIEW.md)

**性質・攻撃:** カメと原寸のオウムは友好と回答した。ゾンビを選んだ名前だけ192pxは敵対としたが、資料付きでは不明／プレイヤーだった。村人の性質は友好と中立の間で揺れ、資料付き原寸でも中立と答えた。画像と同期した攻撃の正解がないため、攻撃判定の正答率は今回も採点しない。「立っているだけ」「のそのそ歩いている」「ひと安心」などの未確認の動作・安全判断は残る。

**陰性対照:** 候補に敵を並べても、05で敵を発見したと断定する回答はなかった。06も敵の種類を選ばなかった。ただし対象を取り違えない一般保証ではなく、06の名前だけ原寸には余分な人影にも読める曖昧な説明が残った。陰性対照は各1場面のみ。

## 読み取れる範囲

- **選べた:** カメと、原寸で見えるオウム。ゾンビは名前だけ192pxで正解名が出たが根拠が不正確。
- **説明データでの改善:** 今回の対応の取れた種類識別では確認できない。192pxオウムは右下の存在への言及が増えたが、候補外としており種類を解けていない。
- **未解決:** カボチャ姿のゾンビの安定した同定、ゴーレムの検出、村人と画像の対象の確かな対応。候補位置・図鑑画像・切抜き等の補助は実施していない。

候補プールはこの小セットの正解種を含むよう評価者が固定した8種類で、ゲーム内の全モブから自動で候補を選ぶ過程は試していない。各画像に正解だけを選んで渡したわけではないが、候補が全モブへ広がった時の性能も示さない。候補順を変える試験や、別場面への再現確認も未実施。
