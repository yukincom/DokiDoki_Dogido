# Google AI概要の短時間取得（2026-09-07）

2026-09-08追記：独立対話への接続と、子どもの後続発話時に同じタブを読み直す任意の `existing_tab_id` を追加した。[追加変更と検証の限界](language-overview-dialogue-2026-09-08.md)。以下は初回取得機能を実装した時点の記録。

## 今回の変更範囲

導入済みの `chrome-web-mcp-macos` に、通常のGoogle検索ページからAI概要と検索結果を取得する任意の機能を追加した。ドギド本体・ワークショップ・音声には未接続。既存の国語テキスト試験の検索先選択も、今回は変更していない。

子どもがブラウザで読むことを主とする。ドギドは読んだことを聞き、必要なら子どもの話に関係するリンク先を読む。AI概要を全文音声出力するための機能ではない。

## API

`google_search` は従来どおりWebリンク検索（`udm=14`）。AI概要を含む通常検索には、`udm` / `tbm` を付けず次のように呼ぶ。

```json
{
  "url": "https://www.google.com/search?q=金床%20なぜ%20読み方%20子供でもわかる&hl=ja",
  "wait_for_ai_overview": true,
  "char_limit": 15000
}
```

- `data.ai_overview.text`: 取得できたAI概要。表示途中の本文や、取得失敗の説明文は返さない。
- `data.ai_overview.status`: コード内の状態。会話モデルにはこの項目や取得エラーを渡さない。
- `data.web`: 同じ検索ページの通常結果を最大5件。タイトル・紹介文・URL。概要がなくても、この一覧があれば `success: true`。
- URLなどの付帯情報は本文と別。通常ページ本文の再抽出、再検索、リンク先の先読みはしない。
- `wait_for_ai_overview` を省略した `fetch_url`、既存 `expected_url` の照合は維持する。

会話モデルへ渡すのは取得した概要本文、または通常結果の一覧だけ。検索結果の紹介文はリンク先の本文を読んだ証拠ではない。必要なリンクが決まってから従来の `fetch_url` で読む。GoogleのAI生成文は公式資料として扱わず、取得の成否と内容の正確さを区別する。

## 待ち方（2026-09-07時点の記録）

2026-09-08にユーザーの指定で、初回8秒目・読み取り要求1回へ変更した。本文の安定検査は1回のブラウザー内処理へまとめた。[現在の待ち方・再読・125件の検証](language-overview-dialogue-2026-09-08.md#初回に間に合わない概要)。以下の4・4.5・5秒方式と実測値は変更前の記録。

検索取得処理の開始を基準に4秒・4.5秒・5秒で最大3回確認する。概要の完了印だけでは冒頭の一文しか出ていないことがあったため、生成中の表示がなく、連続する確認で本文が変わらないことを確認する。採取間隔も確認し、ブラウザ起動の遅れによる連続即時取得を完了扱いしない。

1回のDOM読み取りは最大250ミリ秒。取得処理全体には5.5秒、終了時の接続清掃には250ミリ秒の上限を設ける。クライアントやMCPプロセスの初回起動時間は別。8秒待機・12秒待機の試作は採用しなかった。

表示用Chromeでは待機前に検索タブを選択する。概要が出なくても検索結果は子どもが読めるように残す。MCP所有者が終了すれば専用Chromeも終了する。普段のChromeプロフィールは使わない。

## 確認結果

- 4/4.5/5秒方式での実MCP測定は3件。呼び出し全体は **4.516秒・5.642秒・5.271秒**。いずれもAI概要の後半を含む本文を取得した。初回起動の時間を含む。
- 最新の1件では、確認2回・本文557文字に加え、通常検索結果5件を取得した。
- AI概要のない場合は通常結果を維持すること、生成途中・同じ長さの書換え・折りたたまれた本文・非表示のエラー除外・取消時のタブ清掃・旧APIとURL照合を確認。関連テスト **109件成功、外部検索テスト1件を除外**。
- 実検索では概要の自然な欠落は再現していない。概要欠落時の引き継ぎは実Chrome上の模擬DOMとAPIテストによる確認である。すべての検索で概要が出るという保証ではない。

## 再現

[導入元の指定](../../scripts/chrome-web-source.json)にある固定コミットへ、`chrome-web-reviewed-url-and-ai-overview.patch` を一度だけ適用する。このパッチは以前のURL照合パッチを含む累積版。旧パッチと重ねて適用しない。

```bash
cd .dogido_tools/chrome-web-mcp-macos
.venv/bin/python -m pytest tests/test_google_overview.py tests/test_google_overview_dom.py tests/test_server.py -m 'not live' -q
```

DOMテストには専用のChromeとローカル接続が必要。外部Google検索、LLM、Minecraft、TTSは呼ばない。
