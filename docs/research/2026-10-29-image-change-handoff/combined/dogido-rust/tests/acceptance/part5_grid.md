目的: 8×6の各マスで大きな局所差と明確な明るさ差を検出し、枠・検出メッセージが応答を変えるか測ります。差分率・検出マス数・閾値をモデルへ渡しません。通常の受入試験とは別の実モデル診断です。

同じ判定を固定した後続の [位置説明と結合枠の比較](part5_grid_presentation.md) では、明るさの判定文を両条件へ渡し、変化ありの画像だけで提示方法を比較します。

各マスをさらに8×8の小区画で測ります。一様なRGB差を引いた残差の上位4点平均が60以上、かつ差45以上の点が3点以上連結したマスを局所変化とします。小物をマス全体の平均で消さないためです。

明るさは補正前の符号付き輝度差を使います。マス内の中央値の絶対値18以上、同じ向きの差12以上が64点中40点以上なら明るさ変化とします。全閾値は0〜255の強度単位です。物体名・日の出・成長などの出来事は判定しません。

どちらかを検出したマスだけ、後画像へ1pxのオレンジ枠を追加します。数値・全マスの線・塗りつぶしは描きません。元画像と枠以外の画素を保ち、未検出の画像はバイト同一で複写します。

モデルへ添える文言は、検出ありなら「変化領域をオレンジ色の枠で表示しています。」、検出なしなら「変化がない」です。明るさの方向などの追加説明は渡さず、画像からの応答を確認します。

前回固定した実撮影13組を使い、「前後画像のみ」と「後画像の検出枠＋指定文言」を各3seedで比較します。共通指示・時刻・カメラ移動量・モデル設定は同一です。変更率の条件は今回含めません。

準備にはNumPyとPillowを備えたPythonを使います。この環境では既存のPython 3.11.14を使用しました。新しい実画像を作ったり、既存の撮影内容を補作したりしません。

```sh
python3 dogido-rust/tests/acceptance/part5_model.py prepare-grid --source-trial /path/to/previous-trial --output /path/to/new-grid-trial
python3 dogido-rust/tests/acceptance/part5_model.py run --output /path/to/new-grid-trial --base-url http://127.0.0.1:8080/v1
```

`manifest.json`に閾値・各マスの判定根拠・画像hash、`request-previews.json`に入力全文を残します。`results.jsonl`が生の要求・返答、`REPORT.md`が一覧です。通常の画像試験と同じ送信・解釈・終了コードを使います。

この閾値は同じ13組の実画像で校正した試験値です。未知の撮影列への一般化、連続会話での反復抑制、本体への適用は未検証です。「検出なし」は閾値内という意味で、世界の不変を証明しません。撮影姿勢の変化で画像を除外しません。
