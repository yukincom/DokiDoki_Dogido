# 視認できる範囲と注意を集中する範囲の分離

2026-11-04。追従・待機中の狭い注意箱や一対象への集中を、周囲のモブ・ブロックの視認条件から外す。視認できた周囲から、見に行く対象だけを既存の注意範囲で絞る。

## 既存経路の使い方

- 周辺collectorは既存 `BodyOriginVision` / `BodyVisionGeometry` の水平120度・垂直90度、距離、遮蔽・未ロード判定を使う。
- モブの新規発見は16block。既知の種類は既存 `NearbyComposition.RangeTracker` で21blockまで、実視認が続く場合だけ種類表に残す。個体一覧と移動候補は通常範囲のまま。音源の紐付け・継続も既存の外周を使う。
- ブロックは水平±8・下3／上4の取得範囲を使い、既知種類は各辺から外側5block（水平±13・下8／上9）まで保つ。既存走査・ray上限21block・周辺ロード確認を維持し、狭い注意箱でこの外周を切り落とさない。
- 見に行く候補は同じframeの視認済み個体・ブロックから採り、安心度による注意箱または集中対象を照合する。同種ブロックは注意内で最も近い実視認点を一件残す。注意外の同種が近くても候補を失わない。
- 候補と実行前の再照合にも通常FOVを使う。注意箱の後方部分に入っているだけでは、見えていない対象を新しく選ばない。本人への接近・画像からの対象指定は既存の処理を使う。
- 同じframeのray結果と4096本の上限は共有する。注意の照合で、すでに確認した同じ点の遮蔽を再走査しない。未ロードや上限到達を視認成功へ補完しない。

HTTP形式・モデル呼出し・プロンプト文面は変更しない。集中の命令ID・世代・到着待機・解除と、敵・本人の観測条件は既存のまま。
