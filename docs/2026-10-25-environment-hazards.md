# 環境の危険反応

2026-10-25。主体別の共通観測に溶岩・移動・生命状態を加え、環境の危険に関する返答を既存の会話生成へ接続する。

## 既存経路での役割

Fabricイベント → Rustの環境判断 → 既存 `environment_reaction` → 既存の配送・取消・履歴を使う。HTTP窓口、モデル、前段分類器、生成後の意味検査は増やさない。共有の人格・観測の扱い・`speak / silent` 契約をそのまま使う。

コードが危険の発話機会・優先度・現在性・継続中の重複を判断し、モデルが一回の生成で話す／黙ると本文を選ぶ。生成失敗時だけ既存カタログまたは危険種別の短いfallbackを使う。世界操作、戦闘mode、句の採否・保存はモデルへ渡さない。

## 本人の危険の実測

| 種類 | 発話機会の条件 | 確定しないこと |
|---|---|---|
| 溶岩 | 本人の `touching_lava=true`、火炎耐性なし | 被ダメージの原因・被害量 |
| 炎上 | 本人の `on_fire=true`、溶岩接触trueではない、火炎耐性なし | 出火原因・溶岩から出たという過去 |
| 落下中 | native落下距離が3 block超、垂直速度が負、接地・接水・溶岩接触・登攀・滑空・飛行が全てfalse、乗車なし、低速落下・浮遊なし | 着地先・着地後のダメージ |
| 息不足 | 本人の眼が水中、本人の空気が60 tick以下、水中呼吸・コンジット効果なし | 溺死の確定・救助操作 |

死亡・体力0以下・無敵の実測があるときは機会を出さない。欠測はfalseで埋めず、落下の必要なフラグが不明なら落下警告にしない。未観測の窒息・凍結・奈落等を被ダメージだけから推定しない。

本人の溶岩はnativeの `Entity.isInLava()`。身体の溶岩は同じ受理済み姿勢の箱と流体面を照合し、native同様に正の深さを要求する。水の接触と同じ面一致にはしない。マグマブロックの足元判定、近隣の有害な熱源、溶岩への実接触、炎上は別の事実として渡す。

継続中は各種類について一度だけ考慮する。解消・欠測・次元変更で古い機会を落とす。生成中・待機中に解消した警告、古い観測、ポーズ中の未発話は配送しない。開始済みの一言は終え、実際の敵が現れたら既存の戦闘処理へ譲る。短い落下では生成前に着地して警告が取り消され得る。即時警報や自動救助の保証ではない。

## 環境警告の本文

固定本文だった次の9種類を既存の環境生成へ接続した。

- 暗所の助言、深く暗い水域
- 地表の夕方、洞窟・水中の夕方／夜
- 囲まれた退避場所での助言、朝の案内
- 足元のマグマブロック、近くの有害な熱源
- エンドポータルの枠

既にモデルが返していた暗所入口・暗闇での反応・雷の一言・退避の安堵・ポータル出現も、既存経路を維持する。雷の悲鳴、息を潜める音、音の停止は音／制御として残す。敵の姿・音への即時戦闘警告は従来の戦闘処理が担当する。

材料では周囲の光源・資源と本人の所持品を区別する。退避場所のベッド条件や夜の時間帯は、生成された本文の文字列一致ではなく、選択時の観測条件で照合する。

## 優先順位と相談

被ダメージだけでも既存のpanicは立つが、実際の敵の姿・音・近接個体数がない間は本人の危険を既存の緊急環境枠へ渡せる。被弾原因やmodeは書き換えない。実際の敵、先行する緊急警告、受理済みの応答を優先する。

相談中にも本人の危険だけは伝えられる。現在句・版・未採用案は保持し、危険反応を採用・終了・保存の意思へ読み替えない。生成前に現在値を更新し、生成後は既存の取消・世代・現在性の検査を使う。発話は配送完了後、沈黙はモデルの選択確定後に既存履歴へ残す。
