# ドギド配置検討

リポジトリのルートをローカルHTTPサーバーで開き、`tools/character-placement/` を表示する。

- 通常表示は右上案。画像の大きさ・右余白・上余白と軽い上下動を比較する。
- 作者の `animation/掛け軸資料/画面収録 2026-09-12 14.02.59.mov` を元にしたローカルの `gameplay.mp4` を使用。
  録画の3〜60秒、ゲーム領域854×480、原画面位置x=56/y=66。ゲーム外の黒い余白とタイトルバーのみ除き、体力・満腹度・ホットバーを残す。音声なし・30fps H.264。
- `gameplay.mp4` は録画由来のローカル資料としてGit対象外。別環境では「昼」「夜」の同梱スクリーンショットへ切替できる。
- 掛け軸写真2枚は今後の形・比率・緑系の布と紙の参考。今回のプレビューにはまだ組み込まない。
- Fabricの静止画HUD試作は右下基準のまま。ゲーム用の位置は配置案が決まってから揃える。
